# 《道》正式 UI 子设计说明

更新时间：2026-05-12

## 方位感与小地图

1. 小地图第一版命名为“方位感”，默认显示在正式 HUD 右上角，可用 `M` 开关。
2. 方位感只帮助玩家理解空间：显示玩家朝向、当前近处地貌、附近已理解地点和自然边界气息。
3. 方位感不绘制任务路线、不显示目的地箭头、不显示奖励或完成状态。
4. 未探索或未理解区域不得完整暴露；第一版只读取玩家当前位置附近采样、已经出现的意义地点状态和已经被世界提示过的边界状态。
5. 方位感在开发 HUD 打开或记事本打开时隐藏，避免 UI 堆叠和遮挡。
6. 更新成本必须保持轻量：每帧只做少量地貌采样和已有状态读取，不触发新的区域生成、寻路或流式加载。

## 快速移动规则

1. 快速移动只对“已抵达、已记录、叙事允许、当前安全”的地点开放。
2. “已记录”以记事本地点记录为准，而不是任务完成状态。
3. 危险状态、梦境中、边界过渡中、强制环境事件中不开放快速移动。
4. 快速移动文案应表现为回忆、归路、熟悉路径，不能表现为任务列表或传送菜单。
5. 第一版只保留规则和 UI 入口预留；完整传送、加载遮罩和状态恢复需要等区域流式切换稳定后实现。

## 临时物品栏规则

1. 游戏默认没有持久物品栏。
2. 临时物品栏只在造船、渡河、特殊物品、哲学物品或短流程操作中出现。
3. 临时物品栏随流程开始生成，随流程结束清理，不保留长期收集目标。
4. 临时物品栏不能显示奖励、数量刷取目标或待办清单。
5. 临时物品栏出现时必须优先不遮挡正式 HUD、记事本和交互提示。

# 《道》独立游戏愿景文档

## 1. 项目起源：

现在大部分的游戏基于人们最原始的欲望来开发，每款游戏有固定的游戏模式和模板（如RTS），但是我的游戏和它们不同，这是前所未有的。
我的游戏基于世界规律和涌现范式，基于“道”的理解，基于对于人自己的追寻与探索。欲望只能带来一时的快乐和解脱，但是带来不了真正的快乐和持久的成就感。过去的游戏能够让人们逃离现实世界，而我希望我的游戏能真正改变人。
我该如何实现呢？我想到了《炼金术士》，那是一个牧羊少年历险的故事，他从一个小镇出发，他梦到了宝藏，这是他内心的愿望，是他生来要做的事。过程是丰富的，有着挫折痛苦，有着美丽的女孩带来的温馨，到最后，他发现真正的宝藏就在他出发的地方。
其实，这就是世界，世界是一个巨大的圆，过程才是真正的宝藏，从他一开始出发，其实就注定了结局，他一定会找到属于他的宝藏，因为这段宝藏就是他的历程本身。
我还想到了《老人与海》，老人出海打渔，通过三天三夜的奋战战胜了大鱼，但是没有人亲眼看到，也没有人知道他是多么勇敢。他做的事还有意义吗？事实上，存在即是意义。老人生来就是一个勇敢的人，一个不服输的人，一个硬汉，不管有没有人知道，他都会在那个地方，战胜那条大鱼，因为那就是他自己，一个真正的硬汉。
我还想到了“道”，无为而无不为，不需要指引，玩家自然就会前往。这是贯穿始终的哲学。
因此，这个游戏计划产生了。

## 1. 项目概述

- **游戏类型：** 3D 开放世界 / 动作冒险 / 哲学模拟 / 涌现式叙事
- **核心体验：** 极具沉浸感与美学的“英雄之旅”和“自我找寻”。玩家在没有传统任务面板的指引下，通过感知世界的“规律与预兆”，经历一段由AI独家定制的冒险。
- **技术栈：** Bevy 引擎，有一个挑战，我没有美术，因此我希望大部分材质和地图可以通过程序化生成，选择技术的时候务必考虑这一点。

## 2. 游戏需要什么：

1. 自然世界：类似我的世界一样，必须模拟自然规律，而且我要更进一步，模拟世界运行的规律，这意味着需要有生物群系，生物和人物行为树。
2. 3A大作的质量追求：没有一个美丽的画面效果，是不会有人愿意玩的。
3. 代码优先，程序化生成为主，以最短的时间完成最美观的效果。
4. AI集成，每个人的历险都是不同的。当然，可以先硬编码，留出拓展接口。
5. 第一人称和第三人称的主视角游玩。

## 3. 游戏中不需要什么：

1. 传统的任务模式：那样玩游戏和上班一样，我不能告诉玩家要去干什么，玩家自己愿意干什么都行，当他的所作所为符合他的真正本心时，我们会通过征兆来提醒他。
2. 传统的数值系统：一个人可以用数值去衡量吗？不行。我们只需要宏观上的调节即可，当然具体的小任务的战斗过程中可以暂时有。
3. 花里胡哨的物品和生物：我只需要自然中有的，加上一点哲学物品即可。
4. 极度写实：不需要，只要大致符合自然即可，我的游戏重在世界规律。

## 4. 具体系统设想详细说明:

### 1. 地图：

地图由程序化生成组成，整个世界由多张不同的地图组成，但是地图需要符合一定的规律。

首先，地图必须吸引人，怎么做到这一点呢？有两个重要的方向：标志性景观+标志性环境
就那沙漠地图举例，沙漠中最著名的是什么？是金字塔（巨大的）。沙漠的环境特征是什么？沙尘暴。
我们可以想象一个景象：在沙暴中隐隐约约的金字塔，让人在千米开外就能够看见轮廓，这还是多么吸引人。
因此，我的每一张地图中，有几个必须的要求，首先必须足够大，让人能够自由探索，之后必须有至少一个重要的景观，要么很大，要么很美，要么很有意义。然后就是配套的环境，比如说沙漠自然有沙漠，绿洲，戈壁等等。最后，不同的地图怎么联系到一起，很显然，要有地形地貌和环境过渡，这样才能够自然切换地图。
设计地图的时候，还要从玩法上考虑，每一张地图都有它自己的风格，都有它的危险之处，也有它的资源和重要的地方。俗话说：“风浪越大鱼越贵”，沙漠的危险相比其他场景可能很多，但是它带来的探索价值：比如地下古城，以及产出的稀缺资源，一定是其他地图没有的。在设计的时候，要仔细考虑辩证的关系。
地图之前的切换如何进行呢？事实上，我们不希望玩家能够从一张地图直接看到另一张地图，那样会失去新鲜感，也会在技术上带来困难。地图的切换，一定是不显眼的，只有玩家有欲望去另一张地图，才会收到预兆或者指引。地图的切换有几个例子：比如一个带着重重迷雾的河流，没有渡口。玩家必须收到指引，才能够造船渡河，或者找到渡河的港口。比如一个高耸的大山，玩家只有能够翻过大山，才能看到山后的地图。比如一片海洋，在远处有一个小岛，玩家必须有足够的能力和办法才能够前往。这就是好的地图切换方式。

### 2. 关于剧情如何推进

首先是开篇，我们现在先按照一个特定剧情：《炼金术士》来写，后面再接入AI。
玩家出生在一个村庄里，这是一个美好宁静的村庄，有羊群，有商人，有牧羊人，有大海。他可以在这里和羊群嬉戏，在这里和商人交谈，可以一直待下去。但是他总有一天不满意现状，要去追寻他内心的宝藏。我们在游戏中，通过几天后梦境的展示来体现预示：他在梦里梦到了金字塔下的宝藏。如果他开始找寻前往的办法，那么他会发现，整个宇宙都在合力帮助他，他会慢慢找到去往下一个地图的方法。但是如果他不去找寻，那么这个预示会越来越强烈：可以是天空中飞鸟的方向，可以是遇到了一个神秘的占卜人，可以是很多。直到他前往。
但是如果他一直不前往，那么这种预示就会慢慢消退，直到消失。
直到他努力地想要前往的时候，这个消失的预示才会慢慢回来，否则预示就不再会关照他。
你可以看出这里预兆是如何工作的，以及它的形式是多种多样的。

### 3. 关于感知

在游戏中，预兆如果只是被动的展示，玩家可能无法理解，或者游戏很难只通过行为来确定玩家的意图，这时候，我们可以提供一个主动的技能：感知。
在收集了足够多的意愿之后（比如在海边逗留，就添加想要过海的意愿值），就可以发动感知，此时，预兆就会使用更加明显的方式展现。原本是鸟的飞行轨迹，现在加上鸟的鸣叫声，让玩家可以更容易地发现预兆，从而推进剧情。

### 4. 关于帮助的功能

很多游戏有任务栏，或者会帮助玩家翻译剧情。但是我的游戏不会。我只提供一个帮助功能：记事本。通过记事本，可以记录大大小小的事，可以翻阅之前的对话等。
当然，玩家在游玩过程中，可以从其他NPC那里学到更多的能力，可以解锁更多的帮助功能。
因此UI变得非常简洁，只需要提供一个记事本的入口。

### 5. 关于UI

极简的UI，但是要尽可能帮助玩家游玩。比如小地图是必须有的，地点方向指引，地点快速移动也是可以有的，在这方面我们会不留余力的帮助玩家。
游戏不需要持久的物品栏，只有需要特殊物品的时候，才暂时解锁物品栏，遵循非必要不显示的原则。

### 6. 关于表现力

由于我的游戏非常依赖于预兆，因此需要包含非常多的自然现象：比如天气的变换，星空的闪耀，一年四季的更替，植物的生长发芽，人们的劳作，动物的觅食与迁徙等等。因此在这些方面需要下大力气来完成表现力的展示。

# 《道》独立游戏效果展示文档

对于每一个阶段的任务，必须写一个简单的场景用于展示所有的功能，便于检查是否符合预期。场景可行后，再集成到整个游戏系统中。

## 当前阶段实现

当前项目已经接入“展示模式”，用于单独展示世界系统与征兆系统。

### 展示内容

- 程序化地貌总览：展示草甸、树林、山脊和水域分布。
- 昼夜变化：展示天空明度、太阳方向和整体光照变化。
- 漫游轨迹：展示角色在指定区域中的受控移动。
- 征兆反馈：展示树林、晨光、静水等征兆对应的光效响应。

### 运行方式

推荐直接执行：

```powershell
.\scripts\run-presentation.ps1
```

如果需要快速烟雾验证，可以执行：

```powershell
$env:DAO_PRESENTATION_MODE='1'
$env:DAO_AUTO_EXIT_SECONDS='2.5'
cargo run
```

### 当前规则

- 每一轮较大的系统开发，都应先提供一个可单独检查的展示场景。
- 展示场景应尽量可重复播放，不依赖随机状态碰撞。
- 展示通过后，再将展示阶段的实现保留并集成进正式系统。

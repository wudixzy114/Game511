# 《道》任务清单：生态与人物行为（2026-05-12）

## 最终目标

1. 建立自然生物和人物行为的第一版系统。
2. 让村庄、动物和自然世界看起来在自行运行。
3. 让动物迁徙、觅食、人物劳作和传闻成为征兆载体。
4. 为后续更复杂生态模拟和 AI 叙事提供基础。

## 主要任务1

### 1. 行为系统设计

- [x] 使用 UTF-8 阅读 `文档/游戏介绍.md` 中自然世界、生物、人物行为树和表现力要求。
- [x] 阅读现有 `src/game/world.rs` 中 `WandererPrototype` 相关逻辑。
- [x] 选择第一版行为架构：轻量行为树、状态机或效用 AI。
- [x] 定义通用行为组件：当前状态、目标点、活动范围、情绪/警觉占位、日程占位。
- [x] 定义行为更新频率和性能预算。
- [x] 行为逻辑尽量拆成纯函数，便于测试。

### 2. 动物行为第一版

- [x] 实现羊群行为：聚集、散开、跟随领头点、受惊短暂移动。
- [x] 实现鸟群行为：飞行方向、盘旋、迁飞、作为征兆改变方向。
- [x] 可选实现鱼群或海边动物占位。
- [x] 动物活动范围由地点或群系决定。
- [ ] 动物不应穿过明显障碍或大面积水陆错误。
- [x] 为动物状态推进补充单元测试。

## 主要任务2

### 1. NPC 行为第一版

- [x] 实现牧羊人日程：看羊、回屋、望海、与玩家短对话。
- [x] 实现商人日程：摆摊、休息、传闻对话、看向道路。
- [x] 实现占卜人占位：梦境后出现或在特定地点等待。
- [x] NPC 需要有活动范围和朝向逻辑。
- [x] NPC 对话应写入记事本。
- [x] NPC 不发布传统任务，只提供传闻、观察和世界观线索。
- [x] 为 NPC 日程推进补充单元测试。

### 2. 日程与昼夜联动

- [x] NPC 和动物行为受昼夜影响。
- [x] 白天村庄更活跃，夜晚更安静。
- [x] 特定时刻出现特殊行为，例如商人收摊、鸟群归巢、占卜人点灯。
- [x] 日程变化可被展示模式固定播放。
- [x] 日程状态写入日志，便于调试。

## 主要任务3

### 1. 行为与征兆联动

- [x] 鸟群方向可作为远方征兆。
- [x] 羊群不安可作为梦境或天气变化前兆。
- [x] 商人传闻可暗示沙漠、渡口或金字塔。
- [x] 占卜人可强化梦境解释，但不能变成任务发布者。
- [x] 动物和 NPC 征兆受玩家意愿、感知和旅程阶段影响。
- [x] 为行为征兆选择补充测试。

### 2. 行为与性能

- [ ] 行为更新需要分频或分组，避免每帧重算全部实体。
- [x] 远处动物可降级为群体状态，不必逐个模拟。
- [ ] NPC 和动物生成数量由配置控制。
- [x] 性能埋点接入 `FramePerformance`。
- [ ] 如果行为系统影响帧率，执行性能 baseline、优化后采样和 compare。

## 主要任务4

### 1. 展示模式

- [x] 新增“生态与人物行为展示”。
- [x] 展示覆盖：羊群活动、牧羊人日程、商人日程、鸟群迁飞、行为征兆。
- [x] 展示应可重复，不依赖随机玩家碰撞。
- [x] 展示中需要能看出昼夜或旅程阶段对行为的影响。

### 2. 验证与质量

- [ ] 运行 `cargo fmt --all --check`。
- [ ] 运行 `cargo test`。
- [ ] 运行 `cargo clippy --all-targets -- -D warnings`。
- [ ] 运行探索模式和展示模式自动退出验证。
- [x] 检查 NPC/动物不会残留到主菜单或暂停界面异常运行。

## 本轮实现说明

2026-05-12 本轮新增 `src/game/ecology.rs`，建立轻量生态状态机：羊群会因梦境/征兆变得不安，鸟群可朝边界迁飞，海边鱼群作为自然占位运行；牧羊人、商人、占卜人具备昼夜与梦后意愿驱动的日程。生态征兆进入导演输入与展示模式，并接入 `FramePerformance::Ecology`。更精细的避障和配置化数量仍留到后续。

## 任务额外说明

生态系统第一版要少而准。几种行为鲜明的实体，比大量无意义游荡实体更符合《道》的需求。

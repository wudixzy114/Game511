# 任务清单 2026-05-12 - 村庄资产升级与生活氛围

## 最终目标

1. 把开篇村庄从占位几何升级为玩家愿意停留的生活空间。
2. 用程序化资产表现屋舍、羊圈、集市、水井、海边、外路和日常劳作。
3. 保持村庄不是任务中心，而是“出发前的完整世界”和最终回望的精神原点。

## 村庄建筑资产

### 1. 模块化屋舍

- [ ] 建立程序化房屋模块：墙体、屋顶、梁柱、门、窗、烟囱、台阶。
- [ ] 房屋形态根据地形坡度和朝向微调，不漂浮、不明显插入地面。
- [ ] 增加暖色窗光、微弱炊烟和屋檐阴影，形成清晨/黄昏层次。
- [ ] 每栋房屋有轻微变化，避免复制粘贴感。

### 2. 村庄功能点

- [ ] 羊圈升级为带立柱、横栏、门闩、草垛和踩踏地面的空间。
- [ ] 集市升级为布棚、货箱、陶罐、木桌、称具和商人站位。
- [ ] 水井升级为石圈、绳桶、湿地、井边小路。
- [ ] 海边升级为浅滩、湿沙、泡沫、旧木桩和远处海雾。

## 生活氛围

### 1. 日常活动表现

- [ ] 牧羊人日程与具体地点绑定：看羊、望向村外、回村休息。
- [ ] 商人周围出现少量货物和布棚摆动，表现停留与交易。
- [ ] 羊群活动要能改变局部空间感：聚拢、散开、靠近围栏。
- [ ] 鸟、鱼、烟、海雾等环境元素与时间段联动。

### 2. 开篇情绪

- [ ] 初始出生镜头要让玩家先看到村庄、安全、海与生活，而不是 UI。
- [ ] 梦境前的村庄保持宁静，梦境后出现细微不安：风向、鸟群、村外雾。
- [ ] 如果玩家选择停留，村庄仍然有生活反馈，而不是强迫推进。
- [ ] 如果玩家开始离开，村庄成为可回望的精神坐标。

## 任务额外说明

1. 村庄必须漂亮，但不能变成任务大厅。
2. 村庄资产都应通过程序化资产生产线注册，避免继续散落临时网格。
3. 展示模式必须覆盖“村庄黎明”和“梦后村外小路”。

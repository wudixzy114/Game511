# 任务清单 2026-05-12 - 村庄资产与生活氛围重审

## 审查结论

当前 `village.rs` 和 `assets.rs` 中的房屋、羊圈、集市、水井、海边与炊烟/水纹/布棚摆动等表现，只能算灰盒空间与程序化反馈占位，不能算高质量村庄资产，也不能算生活氛围完成。

当前问题同样是方向错误：

1. 房屋、羊圈、集市、海边都还是盒体拼装，没有材质层次、构造逻辑和真实细部。
2. 炊烟、水纹、泡沫线、尘土、布棚摆动只是最薄的动效提示，不构成空间氛围。
3. 村庄没有建立时间段、天气、风向、湿度、海雾、生活痕迹的统一表现系统。
4. 如果继续在现有几何上加小摆动，只会把错误资产做得更复杂。

因此本任务从“继续堆程序化村庄小件”调整为“保留空间布局与功能点，重建高质量环境表现底座”。

## 最终目标

1. 保留村庄布局、区域语义、功能点位置和主流程作用。
2. 停止把当前盒体房屋与小幅摆动当作正式村庄资产交付。
3. 建立村庄正式资产锚点、氛围控制参数和环境表现槽位。
4. 为后续真实建筑资产、表面材质、体积雾、海岸效果、生活痕迹系统铺底。

## 3A底座任务

### 1. 正式环境资产锚点

- [x] 为房屋、水井、羊圈、集市、海边、路径石建立正式环境资产锚点。
- [x] 默认运行口径切换为底座模式：环境占位动效默认不作为正式氛围展示。
- [ ] 接入真实村庄建筑/道具/海岸场景资源加载与失败回退策略。

### 2. 统一氛围控制层

- [ ] 建立村庄氛围控制参数：时间段、风向、风强、湿度、海雾、炊烟强度、生活密度。
- [ ] 建立“梦前宁静 / 梦后不安”的统一环境状态，而不是分散在若干小件摆动里。
- [ ] 环境状态可驱动后续 VFX、音频、材质和镜头。

### 3. 正式环境表现接口

- [x] 默认关闭占位炊烟、水纹、布棚等轻量动画。
- [ ] 为正式体积烟、海岸泡沫、湿沙过渡、风动布料、脚印/踩踏痕迹预留接口。
- [ ] 为近景、中景、远景环境表现建立不同实现层，不再依赖统一几何部件动画。

### 4. 后续正式村庄资产生产要求

- [ ] 房屋需要结构可信的墙体、屋顶、门窗、梁柱、基础和与地形的落地关系。
- [ ] 羊圈需要真实围栏构造、门、草料、踩踏、污渍和围栏内外空间层次。
- [ ] 集市需要摊布、货物、容器、悬挂物和停留痕迹，而不是单个盒子和棚顶。
- [ ] 海边需要浅滩、湿沙、泡沫、海雾、潮线和岸边旧构件的连续关系。

## 验收口径

1. 当前完成不再声称“村庄资产升级完成”或“生活氛围完成”，只声称“村庄环境底座已纠偏”。
2. 村庄继续承担开篇空间功能，但默认审美验收不再基于当前灰盒和占位动效。
3. 后续只有在接入正式环境资产、环境控制层和展示验证后，才能再次勾选这份清单的大项。

# 任务清单 2026-05-12 - 3A画面基准与镜头表现

## 最终目标

1. 建立《道》的画面评价基准，明确“美丽、沉浸、可迭代”的最低门槛。
2. 让展示模式不再只是功能巡检，而能稳定呈现村庄、梦境、边界、沙漠和夜空的审美瞬间。
3. 在不违背“无任务面板、由世界暗示玩家”的前提下，让镜头、光照和构图服务英雄之旅。

## 画面语言基准

### 1. 确定四个核心画面样张

- [ ] 设计“村庄黎明”：低风、羊群、炊烟、海边晨光、玩家可以选择留下。
- [ ] 设计“梦后海风”：海雾、远方鸟群、外路微光，表现预兆但不显示任务箭头。
- [ ] 设计“迷雾边界”：旧渡口、河雾、山影、可感知但不可直接命令。
- [ ] 设计“沙暴金字塔”：千米外可见轮廓，沙暴间隙显现巨大地标。

### 2. 建立画面验收标准

- [ ] 为每个样张写清楚必须出现的视觉元素、构图重点和情绪目标。
- [ ] 定义近景、中景、远景必须承担的功能：生活细节、路径暗示、世界尺度。
- [ ] 明确禁止项：调试数值主导画面、任务语言、廉价发光箭头、随机堆物。
- [ ] 建立截图检查清单：遮挡、穿插、空地过大、色彩单调、地标不可辨认。

## 镜头与展示模式

### 1. 升级展示导演

- [ ] 为四个核心样张各建立固定展示段落。
- [ ] 每个展示段落提供固定时间、天气、镜头起点、镜头终点和玩家位置。
- [ ] 展示段落必须可重复播放，不能依赖随机碰撞得到好看的画面。
- [ ] 展示段落要覆盖第一人称和第三人称各至少一次。

### 2. 镜头构图规则

- [ ] 增加地标构图辅助：远景地标不被 UI、近景物体或雾完全遮住。
- [ ] 增加玩家尺度构图：第三人称下角色、道路、远方目标同时进入画面。
- [ ] 增加自然边界构图：河雾、山口、海面不能像传送门，要像世界的一部分。
- [ ] 展示镜头移动必须平滑，避免突然跳切破坏沉浸。

## 任务额外说明

1. 本任务不追求一次达到真正商业 3A 资产量，而是先建立可反复检查的画面标尺。
2. 画面标尺必须服务《道》的精髓：世界自己在运行，玩家自己愿意前往，过程就是宝藏。
3. 完成后运行 `.\scripts\run-presentation.ps1` 做展示验证。

# 《道》任务清单：意愿与感知系统（2026-05-12）

## 最终目标

1. 建立玩家意愿记录系统，让世界能理解玩家正在关注什么。
2. 实现主动“感知”能力，让玩家在合适情境下主动请求更清晰的预兆。
3. 让征兆具备增强、衰退和回归规则。
4. 保持非任务化表达，不把感知变成路线导航。

## 主要任务1

### 1. 需求与边界确认

- [ ] 使用 UTF-8 阅读 `文档/游戏介绍.md` 中“关于剧情如何推进”和“关于感知”。
- [ ] 阅读 `src/game/signs.rs`、`src/game/journey.rs`、`src/game/places.rs`，确认现有征兆和旅程状态。
- [ ] 明确感知不是侦查按钮、不是任务追踪按钮、不是小地图导航按钮。
- [ ] 明确第一版感知只强化已有征兆，不凭空创造确定答案。
- [ ] 明确玩家意愿来自行为，而不是 UI 选择题。

### 2. 意愿状态设计

- [ ] 新增 `IntentState` 或旅程意愿子模块。
- [ ] 定义意愿类型：向海、向山、向村外、向人群、向动物、向梦境地标、向静处。
- [ ] 定义意愿强度、最近更新时间、衰减速度和来源。
- [ ] 记录行为来源：停留、注视、接近、反复返回、与 NPC 对话、进入特定群系。
- [ ] 意愿状态随游戏会话初始化和清理。
- [ ] 意愿变化写入日志，便于调试。
- [ ] 为意愿累积和衰减补充单元测试。

## 主要任务2

### 1. 行为采样

- [ ] 基于玩家位置记录停留意愿。
- [ ] 基于相机朝向记录注视意愿。
- [ ] 基于重复接近海边、山口、村外道路等地点记录方向意愿。
- [ ] 基于 NPC 对话关键词或对话类别记录叙事意愿。
- [ ] 基于梦境后行为记录是否“寻找宝藏”。
- [ ] 对采样进行平滑处理，避免玩家短暂路过就触发强意愿。
- [ ] 采样逻辑要可测试，尽量将纯逻辑从 Bevy 系统中拆出。

### 2. 意愿与旅程导演衔接

- [ ] 旅程导演读取意愿状态选择候选征兆。
- [ ] 当意愿与梦境或长期目标一致时，提高相关征兆权重。
- [ ] 当意愿与当前旅程无关时，允许出现局部自然回应，而不是强行拉回主线。
- [ ] 如果玩家长时间违背梦境召唤，相关征兆逐渐衰退。
- [ ] 如果玩家重新接近相关地点或行为，相关征兆逐渐回归。
- [ ] 为权重计算补充单元测试。

## 主要任务3

### 1. 感知输入与状态

- [ ] 添加感知输入键位，优先使用一个单键，不影响现有移动和暂停。
- [ ] 新增 `PerceptionState`，记录是否可用、冷却、持续时间、强度和结果类型。
- [ ] 感知可用条件至少考虑：意愿强度、平静度、当前征兆、当前地点。
- [ ] 感知失败时给自然反馈，不弹错误提示。
- [ ] 感知成功时进入短时间增强状态。
- [ ] 感知输入、成功、失败、冷却写入日志。
- [ ] 为感知可用性判定补充单元测试。

### 2. 感知表现增强

- [ ] 感知成功时提高当前征兆可见性或持续时间。
- [ ] 感知成功时可强化远景光、雾、风、鸟群方向或地标轮廓。
- [ ] 感知成功时可预留声音事件接口，例如鸟鸣、风声、水声。
- [ ] 感知表现必须与当前意愿和世界情境匹配。
- [ ] 感知不显示“目标距离”或“请前往某地”。
- [ ] 感知结束后表现自然衰减。

## 主要任务4

### 1. 征兆增强、衰退和回归

- [ ] 扩展 `SignState`，区分基础征兆强度和感知增强强度。
- [ ] 增加征兆衰退状态，表示玩家长期不回应。
- [ ] 增加征兆回归状态，表示玩家重新寻找。
- [ ] 征兆强度受意愿、平静、地点、梦境阶段和感知状态共同影响。
- [ ] 相关状态变化必须写日志。
- [ ] 为征兆增强、衰退、回归补充单元测试。

### 2. UI 与记事本衔接

- [ ] 正式 HUD 只显示极简感知反馈。
- [ ] 开发 HUD 可显示意愿强度、感知冷却和征兆状态。
- [ ] 感知到重要征兆后，向记事本系统发送记录事件。
- [ ] 如果记事本尚未实现，先通过旅程记忆保存兼容事件。

## 主要任务5

### 1. 展示与验证

- [ ] 新增“意愿与感知展示”。
- [ ] 展示覆盖：玩家停留积累意愿、感知成功、征兆增强、征兆衰退、征兆回归。
- [ ] 运行 `cargo fmt --all --check`。
- [ ] 运行 `cargo test`。
- [ ] 运行 `cargo clippy --all-targets -- -D warnings`。
- [ ] 运行探索模式和展示模式自动退出验证。

## 任务额外说明

感知系统是《道》的核心交互之一。实现时要坚持“帮助玩家理解世界”，不能把它做成任务追踪、透视扫描或导航箭头。

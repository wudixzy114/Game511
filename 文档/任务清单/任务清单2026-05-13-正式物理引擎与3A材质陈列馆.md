# 任务清单 2026-05-13 - 正式物理引擎与3A材质陈列馆

## 最终目标

1. 为《道》建立正式物理引擎路线，替代当前只覆盖地形和少量村庄物件的手写碰撞代理。
2. 建立可批量生成、可浏览、可对比、可验收的 3A 程序化材质陈列馆。
3. 让后续开放世界开发具备可靠的碰撞、触发、射线检测、刚体、角色控制和材质质量验收基础。

## 现状判断

1. 当前项目没有完整物理引擎依赖。
2. 现有能力主要包括 `TerrainCollisionProxy`、玩家胶囊体地形接触、第三人称相机地形避让、村庄物件碰撞代理。
3. 这套实现适合早期验证，但不适合大型开放世界长期开发，缺少刚体、复杂碰撞体、触发器、查询、射线、碰撞层、调试绘制和稳定物理步进。

## 主要任务1

### 1. 正式物理引擎选型与接入

- [x] 调研与当前 Bevy 版本兼容的成熟物理方案，重点比较 Rapier、Avian/XPBD 等路线。
- [x] 明确物理引擎承担的职责：角色控制、静态场景碰撞、动态刚体、触发区域、射线检测、传感器和调试可视化。
- [x] 保留当前地形采样作为高度/地貌查询来源，但将玩家和物体碰撞逐步迁移到正式物理世界。
- [x] 建立物理插件初始化、固定步进、碰撞层、查询接口和调试开关。

### 2. 地形、建筑和角色碰撞迁移

- [x] 将流式地形块生成对应的静态地形碰撞体，并与渲染 LOD 解耦。
- [x] 将程序化资产规格中的 `ProceduralCollision` 从语义字段升级为真实 collider 生成规则。
- [x] 为房屋墙体、门洞、室内道具、井、羊圈、摊位、NPC 和动物生成正式碰撞体。
- [ ] 支持 trigger/sensor，用于门、可交互物、区域入口、征兆感知和材质陈列馆展品选择。（本轮完成可交互物与陈列馆展品传感器；区域入口和征兆传感器待接入对应玩法状态。）
- [x] 增加物理调试显示，能够查看 collider、触发器、角色胶囊体和射线。

### 3. 玩家控制与物理查询

- [ ] 将玩家移动从手写地形接触逐步迁移到物理角色控制器或等价可靠实现。（本轮已接入玩家 kinematic capsule，移动求解仍由原玩家系统过渡。）
- [ ] 支持斜坡、台阶、地面贴合、跳跃、落地、推挤、阻挡和相机碰撞。（旧玩家系统继续提供基础体验，正式物理角色控制仍待迁移。）
- [x] 增加向前射线/形状查询，用于门交互、观察、拾取、材质展品查看。
- [x] 为物理阶段加入性能埋点，覆盖 broad phase、narrow phase、solver、query 和 collider streaming。（broad/solver 先以物理阶段键占位，后续可接更细的 Avian schedule 统计。）

## 主要任务2

### 1. 3A程序化材质库

- [x] 建立统一材质定义结构，至少包含名称、类别、颜色、粗糙度、金属度、法线强度、湿润度、尘土、风蚀、边缘磨损和适用场景。
- [x] 批量生成第一批材质族：泥墙、石材、旧木、深色屋顶、布料、湿沙、干沙、草甸、苔藓、芦苇、羊毛、陶器、水面、旧金属、遗迹石、沙漠石。
- [x] 每个材质都需要近看、中距、斜光、湿润/干燥状态对比。
- [x] 材质必须走程序化路线，允许后续接纹理烘焙或缓存，但不能退回单色 `StandardMaterial`。

### 2. 材质陈列馆

- [x] 新增一个独立展示模式或展示场景：`MaterialGallery`。
- [x] 每个材质生成一个固定展台，包含球体、立方体、斜面、粗糙地面片四种测试几何。
- [ ] 展台显示材质名称、类别和关键参数，但不使用任务式 UI 语言。（世界空间 Text2d 标签会在错误相机下堆到屏幕中心，本轮先移除；后续改为不遮挡的 UI 面板或展台贴牌。）
- [x] 支持按类别浏览：地表、建筑、木材、布料、金属、水体、生物、遗迹。
- [x] 支持固定光照、斜向强光、阴天漫射、夜间暖光四种光照预设。
- [x] 支持截图落盘和材质清单导出，便于逐个确认是否满意。

### 3. 验收与性能

- [x] 材质陈列馆必须能一次性展示大批量材质，不因材质数量增加导致启动或浏览明显卡顿。
- [x] 每个材质需要有稳定 ID，后续资产引用同一材质时能追溯到陈列馆中的展品。
- [x] 新增材质生成、材质上传和陈列馆渲染阶段的性能埋点。
- [x] 形成“材质满意 / 需要修改 / 禁用”的验收状态记录。

## 任务额外说明

1. 正式物理引擎是大型开放世界的基础设施，不应长期依赖手写碰撞代理。
2. 当前手写碰撞可以作为过渡层保留，但新增系统应朝正式物理世界迁移。
3. 材质陈列馆是画质验收工具，不是玩法内容；它的第一目标是让每一种材质都能被单独审查。
4. 这项任务完成前，不应继续大规模扩展建筑、生态和地标资产，否则资产质量会继续被低质量材质拖住。

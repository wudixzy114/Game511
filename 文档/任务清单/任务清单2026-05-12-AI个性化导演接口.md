# 《道》任务清单：AI 个性化导演接口（2026-05-12）

## 最终目标

1. 在不依赖在线 AI 的前提下，建立可测试、可回放的旅程导演接口。
2. 让硬编码导演和未来 AI 导演共用同一套输入输出协议。
3. 允许 AI 个性化梦境、对话、征兆文本和地点语义建议。
4. 保证 AI 建议必须经过世界规则校验，不能破坏游戏规律。

## 主要任务1

### 1. 接口边界设计

- [x] 使用 UTF-8 阅读 `文档/游戏介绍.md` 中 AI 集成和独家历险要求。
- [x] 阅读 `src/game/journey.rs`、`src/game/signs.rs`、`src/game/places.rs`、`src/game/presentation.rs`。
- [x] 明确 AI 是上层导演，不是世界模拟本身。
- [x] 明确在线 AI 不作为当前运行必需依赖。
- [x] 明确硬编码导演必须始终可用。
- [x] 设计 `JourneyDirector` 接口草案。

### 2. 导演输入 schema

- [x] 定义导演输入：玩家位置、当前区域、已知地点、旅程阶段、梦境状态、意愿状态、记事本摘要。
- [x] 定义可选输入：最近对话、最近征兆、天气、NPC 状态。
- [x] 输入需要可序列化，便于日志和未来 AI 调用。
- [x] 输入不能包含不必要的大型世界数据，只传摘要和候选。
- [x] 为输入构建补充单元测试。

## 主要任务2

### 1. 导演输出 schema

- [x] 定义导演输出类型：候选征兆、候选梦境、候选对话、候选地点、候选环境回应。
- [x] 输出必须是建议，不是强制命令。
- [x] 输出包含语义标签、强度、持续时间、前置条件和回退文案。
- [x] 输出不能直接生成任务目标。
- [x] 输出需要经过规则校验才能采纳。
- [x] 为输出校验补充单元测试。

### 2. 硬编码导演实现

- [ ] 将现有旅程推进中“选择目标、触发征兆、写入记忆”的逻辑逐步整理到硬编码导演。
- [x] 硬编码导演实现与 AI 导演相同接口。
- [x] 硬编码导演覆盖村庄梦境、第一段旅程、沙漠金字塔候选。
- [x] 硬编码导演输出写入日志。
- [x] 硬编码导演必须在无网络、无密钥情况下正常运行。

## 本轮实现说明

2026-05-12 本轮新增 `src/game/director.rs`，定义 `JourneyDirector` trait、`HardcodedJourneyDirector`、可序列化 `DirectorInput` / `DirectorOutput` / `DirectorSuggestion`，并加入世界规则校验与拒绝原因。导演输入只包含玩家位置、当前区域、旅程/梦境、主导意愿、记事本摘要、金字塔信号和生态征兆等摘要，不依赖在线 AI。AI provider、异步请求和密钥配置仍未接入默认运行路径，保持离线硬编码回退。

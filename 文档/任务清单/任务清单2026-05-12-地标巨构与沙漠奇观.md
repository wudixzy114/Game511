# 任务清单 2026-05-12 - 地标巨构与沙漠奇观

## 最终目标

1. 把沙漠金字塔从简单轮廓升级为第一张地图的核心视觉奇观。
2. 让沙漠地图形成“危险越大、探索价值越高”的辩证关系。
3. 让梦境、感知、沙暴、绿洲、遗迹和地标尺度形成完整体验链。

## 金字塔地标升级

### 1. 巨构层次

- [ ] 为金字塔生成阶梯、边缘磨损、入口阴影、半埋底座和残破石块。
- [ ] 增加远景 silhouette、中景简化面、近景可探索结构三档 LOD。
- [ ] 金字塔必须在沙暴中时隐时现，而不是一直清晰或一直不可见。
- [ ] 近景地标需要有可围绕探索的空间，不只是一个大型实体。

### 2. 周边地点

- [ ] 绿洲升级为水面、棕榈或耐旱植物、湿沙和动物痕迹。
- [ ] 残墙升级为可读的废墟群，形成通往金字塔的空间节奏。
- [ ] 地下古城入口做第一版占位：半埋门楣、风声、黑暗开口。
- [ ] 稀缺资源先作为环境语义占位，不做传统采集刷取。

## 沙漠环境

### 1. 沙丘与戈壁

- [ ] 沙丘方向由风场决定，靠近地标时形成构图引导。
- [ ] 戈壁区域加入碎石、硬地、裂纹和低矮风蚀石。
- [ ] 绿洲周围湿度、植被和动物痕迹自然过渡。
- [ ] 沙漠行走需要有距离感、迷失感和偶尔的视觉奖励。

### 2. 沙暴与感知

- [ ] 沙暴分为远处尘墙、近处沙粒、天空变色、地表低尘四层表现。
- [ ] 感知激活时沙暴短暂让出地标轮廓，但不直接给路线。
- [ ] 梦境回响影响金字塔显现频率和强度。
- [ ] 长期无视远方时，地标提示逐步退回自然状态。

## 任务额外说明

1. 金字塔不是奖励点，而是玩家内心愿望的远方形体。
2. 沙漠必须同时美丽、危险、有价值，不能只是换色地形。
3. 展示模式必须有“沙暴中远见金字塔”和“金字塔近景废墟”两个镜头。

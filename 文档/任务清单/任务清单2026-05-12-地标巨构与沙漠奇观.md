# 任务清单 2026-05-12 - 地标巨构与沙漠奇观

## 最终目标

1. 把金字塔及其周边空间做成真正具备远方召唤力的高质量程序化奇观。
2. 让沙暴、风场、梦境、感知和地标显现形成统一体验链。
3. 地标正式路线必须是高质量程序化巨构，而不是等待外部高模替换。

## 阶段定位

1. 本任务当前属于中后段旅程支撑任务，不高于“开篇牧羊与渡河探索闭环”。
2. 当前阶段只保留与梦境远方召唤相关的最低必要维护，不继续抢占开篇开发优先级。
3. 第一条边界穿越和城镇准备阶段完成后，再继续推进沙漠奇观的深度升级。

## 核心任务

### 1. 金字塔与周边空间

- [x] 已具备金字塔、残墙、绿洲、遗物和显隐逻辑的第一版程序化底座。
- [ ] 提升金字塔近景构造：阶梯、磨损、入口、埋沙关系、结构阴影和构图轮廓。
- [ ] 提升绿洲、残墙、湿沙、风蚀石、地下入口和动物痕迹之间的空间节奏。
- [ ] 让地标近中远三档蓝图继续拉开质量差距，避免中远景过早退化。

### 2. 沙暴、风场与显隐

- [x] 统一风场已经建立，可作为地标显现的公共驱动输入。
- [ ] 地标显现必须进一步读取 `WindField` 与 `EnvironmentSnapshot`，形成“沙暴吞没 - 间隙显现 - 感知强化”的连续表现。
- [ ] 梦后回响和长期意愿要调制地标显现频率与轮廓强度，但不能变成任务箭头。
- [ ] 展示模式要稳定输出“沙暴中远见金字塔”和“近景废墟环绕”样张。

## 任务额外说明

1. 金字塔不是奖励盒子，而是玩家内心愿望的远方形体。
2. 沙漠的危险、美丽和值得前往，必须同时成立。

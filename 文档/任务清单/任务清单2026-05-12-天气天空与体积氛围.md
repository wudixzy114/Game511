# 任务清单 2026-05-12 - 天气天空与体积氛围

## 最终目标

1. 把天气从状态切换升级为真正塑造情绪、尺度、征兆和地标显现的高质量表现系统。
2. 把统一风场、天空层次、云、海雾、雨、雪、沙暴和地表响应整合为正式底座。
3. 程序化天气与体积氛围必须是正式路线，而不是简单粒子补丁。

## 核心任务

### 1. 统一环境状态

- [x] 新增 `EnvironmentSnapshot`，统一提供天气、可见度、湿度、雾密度、云量、海雾等公共状态。
- [x] 新增 `WindField`，统一提供风向、风速、阵风、旋涡和征兆偏置。
- [x] 为环境快照与风场新增日志输出，支持展示复盘。
- [ ] 将更多系统接入环境快照与风场，而不是重复各自推导天气表现。

### 2. 天空、雾与天气表现

- [ ] 升级天空层次、云带、星带、日夜色彩和区域色彩基准。
- [ ] 升级雨、雪、沙暴为近景粒子、中景幕墙、远景变色、地表响应四层结构。
- [ ] 让海雾、晨光、黄昏和梦后颜色短暂变化更具构图价值。
- [ ] 为地标和征兆建立“风场变化先行、视觉显现随后”的表现顺序。

## 本轮进展

1. 环境快照与统一风场底座已经落地。
2. 后续村庄、生态、地表和地标都可以直接读取同一套天气与风输入。

## 任务额外说明

1. 这份任务的完成标准不是“天气种类够多”，而是“玩家能感到世界在呼吸”。
2. 气氛升级必须同时关注展示样张与性能报告。

# 任务清单 2026-05-12 - 天气天空与体积氛围

## 最终目标

1. 把天气从状态切换升级为能塑造情绪、地标和征兆的表现系统。
2. 强化天空、云、雾、雨、雪、沙、海雾和星空，使世界具有 3A 方向的沉浸感。
3. 让天气既遵循区域规律，也能被梦境、感知和旅程阶段短暂调制。

## 天空与光照

### 1. 天空层次

- [ ] 升级昼夜天空渐变，减少纯色背景感。
- [ ] 增加云层或云带的程序化表现，支持晴天、阴天、风暴、沙暴、海雾。
- [ ] 星空需要有亮度层级、银河或星带方向，避免均匀点阵感。
- [ ] 月光、晨光、黄昏光要与雾和地表材质共同作用。

### 2. 光照与色彩

- [ ] 建立区域色彩基准：村庄暖、海雾冷、山口硬、沙漠金灰、梦境高对比。
- [ ] 调整环境光、主光、雾色和地表材质，避免所有画面落入单一色调。
- [ ] 为梦境和感知建立短暂色彩变化规则。
- [ ] 保留开发配置，方便不同机器上降低强度。

## 体积氛围与粒子

### 1. 雾、雨、雪、沙

- [ ] 雾按高度、距离和区域变化，不只是全屏降低能见度。
- [ ] 雨需要有落线、地表湿润和远处灰幕三层表现。
- [ ] 雪需要有缓慢飘落、地表积雪和远山淡化。
- [ ] 沙暴需要有近处沙粒、远处尘墙和地平线吞没感。

### 2. 风场

- [ ] 建立简单风场资源，供草、布、沙、鸟群、烟和天气粒子共用。
- [ ] 风场可以成为征兆载体：方向变得一致、突然停住、短暂回旋。
- [ ] 风场强度随区域和天气变化。
- [ ] 风场状态写入日志，便于复盘展示画面差异。

## 任务额外说明

1. 氛围系统必须让玩家“感觉到世界在呼吸”，不是单纯加粒子。
2. 天气调制不能频繁强行指路，只在意愿、梦境或感知满足时加强。
3. 完成后需要性能对比，重点看 p95 和 p99 帧耗时。

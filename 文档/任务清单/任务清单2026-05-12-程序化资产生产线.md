# 任务清单 2026-05-12 - 程序化资产生产线

## 最终目标

1. 建立统一的程序化资产生产线，避免村庄、地标、生态、地表细节各自临时生成几何体。
2. 让程序化资产具备语义、LOD、材质、碰撞、展示和征兆绑定能力。
3. 用代码优先的方式，为后续接近 3A 的画面迭代提供稳定基础。

## 资产语法与注册表

### 1. 建立资产描述结构

- [ ] 设计 `ProceduralAssetSpec`：记录资产类型、语义标签、种子、尺寸、材质族和 LOD 策略。
- [ ] 设计 `ProceduralAssetRegistry`：集中注册房屋、树、岩石、草、遗迹、动物、NPC、地标部件。
- [ ] 资产必须能通过稳定种子复现，方便截图、性能和 bug 复盘。
- [ ] 资产语义必须能被征兆、感知、记事本和导演查询。

### 2. 统一生成入口

- [ ] 把直接散落在系统里的简单 `Cuboid` / `Capsule` 占位逐步迁移到资产工厂。
- [ ] 提供近景网格、中景简化、远景 impostor 三档生成接口。
- [ ] 生成接口必须返回实体根节点，便于统一清理、隐藏、LOD 切换和性能统计。
- [ ] 资产生成失败必须记录日志，不能静默缺失。

## 材质与细节挂接

### 1. 材质族

- [ ] 建立石材、木材、泥墙、布料、羊毛、沙、湿地、水面、古物等基础材质族。
- [ ] 每个材质族至少支持基础色、粗糙度、法线或高度扰动中的两项程序化变化。
- [ ] 同类资产不能只靠纯色区分，需要有可读的纹理或几何细节。
- [ ] 材质参数接入配置，方便快速调色和性能回退。

### 2. 资产语义挂接

- [ ] 地标资产支持梦境、征兆、感知高亮和记事本记录。
- [ ] 村庄资产支持生活语义：居住、交易、饮水、牧羊、离村。
- [ ] 生态资产支持行为语义：觅食、迁徙、惊扰、停栖。
- [ ] 自然边界资产支持状态语义：隐藏、被提示、可通过、已通过。

## 性能与维护

### 1. LOD 与批处理

- [ ] 定义每类资产的最大近景数量、中景数量和远景数量。
- [ ] 草、石、灌木等高频资产必须批处理或合并网格。
- [ ] 动物、NPC 和重要地标可以保留独立实体，但必须有可见距离和更新分频。
- [ ] 所有重型生成阶段接入 `FramePerformance`。

## 任务额外说明

1. 程序化资产生产线是后续所有画面升级的基础任务，优先级高于继续堆单个占位模型。
2. 资产系统不能只为好看服务，还必须保留“世界规律”和“征兆语义”。
3. 完成后需要补充单元测试验证稳定种子、LOD 选择和语义标签。

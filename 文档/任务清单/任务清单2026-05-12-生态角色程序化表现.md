# 任务清单 2026-05-12 - 生态角色程序化表现

## 最终目标

1. 把羊、鸟、鱼、牧羊人、商人、占卜人从胶囊体占位升级为可辨识的程序化角色。
2. 建立轻量程序化动画，让生态行为能被玩家看懂。
3. 让动物和人物成为征兆载体，而不是只做背景装饰。

## 动物资产与动画

### 1. 羊群

- [ ] 生成羊的基础身体：躯干、头、四肢、耳朵、羊毛体积。
- [ ] 增加行走、低头吃草、抬头、受惊散开四类程序化姿态。
- [ ] 羊群移动要有个体偏差，避免整齐同步。
- [ ] 羊群不安时朝风、鸟群或村外方向产生可读的集体变化。

### 2. 鸟群与鱼群

- [ ] 鸟从胶囊体升级为简单翅膀剪影，支持拍翼频率和滑翔。
- [ ] 鸟群迁飞时形成可读方向线，但不能像 UI 箭头。
- [ ] 鱼群在浅水或绿洲中有闪动、转向和集群表现。
- [ ] 远距离动物自动降级为剪影或粒子式群体。

## NPC 资产与动作

### 1. 人物辨识

- [ ] 牧羊人、商人、占卜人使用不同轮廓、服饰色块和手持物。
- [ ] 建立站立、行走、交谈、看向远方、休息五类基础姿态。
- [ ] 交互时 NPC 需要转向玩家，并有轻微身体或手部动作。
- [ ] 远距离 NPC 使用简化轮廓，近距离保留语义特征。

### 2. 行为与征兆

- [ ] 牧羊人望向村外时，应与羊群不安、梦后风向形成同一组暗示。
- [ ] 商人传闻触发时，周围货物或布棚可以被风带动，暗示沙漠主题。
- [ ] 占卜人出现时使用灯、雾、静止姿态，而不是弹出任务标记。
- [ ] 对话记录进入记事本，不能生成待办项。

## 任务额外说明

1. 角色表现先追求“可辨识、有生命、能承载预兆”，不追求高成本写实。
2. 动画必须由行为状态驱动，而不是独立循环装饰。
3. 需要补充性能分频和可见距离测试。

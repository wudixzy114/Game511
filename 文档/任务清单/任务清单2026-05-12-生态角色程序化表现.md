# 任务清单 2026-05-12 - 生态角色表现重审与3A底座重建

## 审查结论

当前 `assets.rs`、`ecology.rs` 中的羊、鸟、鱼、牧羊人、商人、占卜人，只能算行为可视化占位，不能算角色资产完成，也不能算 3A 方向的角色表现完成。

问题不是“精度不够”，而是方向错误：

1. 角色轮廓由圆柱、球体、杆件直接拼装，不能形成可信的近景观感。
2. 轻量摆动动画只能证明状态驱动链路存在，不能承担正式角色表演。
3. 近景、中景、远景没有真实替身体系，只有简化几何和可见距离裁剪。
4. 现有实现如果继续扩展，只会放大临时方案的技术债。

因此本任务从“继续做程序化角色外形”调整为“保留行为系统，重建高质量角色表现底座”。

## 最终目标

1. 保留羊群、鸟群、鱼群、牧羊人、商人、占卜人的行为与征兆逻辑。
2. 停止把玩具化几何占位当作正式角色资产交付。
3. 建立正式角色资产接入点、展示锚点、LOD 策略和替身体系。
4. 为后续高质量角色模型、绑定动画、材质和 VFX 接入铺底。

## 3A底座任务

- [x] 为羊、鸟、鱼、牧羊人、商人、占卜人建立正式资产锚点与推荐场景路径。

- [x] 默认运行口径切换为底座模式：角色占位默认不再作为正式展示。
- [ ] 接入真实 `glb/scene` 角色资源加载与失败回退策略。

### 2. 角色 LOD 与替身体系

- [x] 为角色保留 Near/Mid/Far 语义，但将当前几何 LOD 明确为代理层。

- [ ] 角色 LOD 切换策略接入展示验证。

### 3. 动画与行为分层

- [x] 保留行为状态驱动链路。

### 4. 后续正式角色生产要求

- [ ] 羊需要可读头颈、躯干、四肢比例和毛体积层次，近景不能再是几何拼块。
- [ ] 鸟需要可信飞行 silhouette 和群体方向感，不能像 UI 箭头，也不能像盒子扇动。

- [ ] 牧羊人、商人、占卜人需要独立 silhouette、服装层、道具层和站姿语言。

## 验收口径

1. 当前完成不再声称“角色资产完成”，只声称“角色表现底座已纠偏”。
2. 行为系统继续可运行，但默认展示不依赖玩具化角色近景。
3. 后续只有在接入正式角色资源、替身体系和展示验证后，才能再次勾选“生态角色表现完成”。

# 任务清单 2026-05-13 - 地形材质3A化第一阶段

## 最终目标

1. 把当前世界地表从“程序化色块 + 简单散布”的玩具感，升级到具备 3A 方向可信度的程序化地表底座。
2. 优先提升玩家近景最容易盯住的区域：海边村庄、村外草地、迷雾河岸、对岸入口。
3. 保持程序化路线，不引入外部贴图依赖作为正式主方案。

## 主要任务1

### 1. 地表纹理底座升级

- [x] 强化 `terrain_texture_color`，增加湿岸、沙纹、矿物断裂、草地色差和不同群系的综合色变化。
- [x] 让草地、沙地、戈壁、绿洲、水岸之间的颜色关系更明显，减少单块涂色感。
- [ ] 继续增加程序化“法线假象”与明暗节奏，让近景移动时更像材质而不是贴图。
- [ ] 让地表继续正式读取环境快照和风场，支持雨后湿润、海雾冷湿和沙暴覆尘。

### 2. 近景散布与细节层次

- [x] 调整草地、河岸、沙地、绿洲、山脊的散布阈值和构件尺度，拉开不同地貌的高频节奏。
- [x] 优化近景散布材质色相和粗糙度，减少“塑料小摆件”观感。
- [ ] 增加湿岸、碎石、踩踏、风向纹理和河岸过渡的专门细节批次。
- [ ] 为村外草地、迷雾河岸、对岸入口补正式近景展示样张。

## 主要任务2

### 1. 第二阶段视觉目标

- [ ] 建立按区域区分的地表风格基准：村庄海岸、边界河岸、草地林地、沙地戈壁。
- [ ] 提升远中近景的一致性，避免近景细节起来后远景仍然像旧原型。
- [ ] 为性能报告补充地表细节批次的观测口径，防止质量升级失控。

## 任务额外说明

1. 这份任务不是脱离主线的独立美术任务，而是当前探索竖切的支撑战线。
2. 当前完成标准不是“照片级写实”，而是“可信、细腻、有尺度、不再像玩具”。

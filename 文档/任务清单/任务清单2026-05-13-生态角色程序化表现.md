# 任务清单 2026-05-12 - 生态角色程序化表现

## 最终目标

1. 让羊、鸟、鱼、牧羊人、商人、占卜人成为高质量、可辨识、可作为征兆载体的正式程序化角色。
2. 正式路线是高质量程序化角色配方、程序化替身和程序化表现分层，而不是依赖外部角色资源兜底。
3. 角色行为、动画、风场、征兆和展示验证必须在同一条正式管线里协同工作。

## 阶段定位

1. 本任务当前属于 `任务清单2026-05-13-开篇牧羊与渡河探索闭环.md` 的支撑任务，不单独作为第一优先级推进。
2. 当前阶段应优先服务羊群、鸟群、牧羊人、商人和占卜人这几类开篇征兆载体。
3. 不允许用纯角色审美升级替代开篇玩法、离村动机和边界穿越的主任务。

## 程序化角色正式路线

### 1. 角色配方与替身体系

- [x] 为羊、鸟、鱼、牧羊人、商人、占卜人建立正式程序化资产锚点。
- [x] 将角色锚点语义纠偏为程序化配方路径。
- [ ] 建立更高质量的近景角色蓝图：轮廓、肢体比例、体量分布、材质层次。
- [ ] 建立中景简化角色与远景群体代理的正式替身体系。

### 2. 行为到表现的分层

- [x] 保留行为状态机、意愿联动、征兆联动和互动记录。
- [ ] 让角色表演进一步读取统一风场、天气状态和征兆强度。
- [ ] 建立“行为状态 -> 动画状态 -> 视觉强调 -> 音频提示”的正式表现链路。
- [ ] 为惊群、迁飞、驻足、凝视、传闻时刻建立更强的视觉辨识度。

### 3. 审美与展示要求

- [ ] 羊必须具备可信的头颈、躯干、毛体积和步态，不再只是几何暗示。
- [ ] 鸟群迁飞需要形成高质量的方向感和远景节奏，而不是像 UI 箭头。
- [ ] 鱼群需要形成水体内反光、转向和群游节奏。
- [ ] 展示模式必须有生态征兆样张，并验证中远景可读性。

## 本轮进展

1. 角色正式路线继续明确为程序化配方，而不是外部资源接管。
2. 统一风场已建立，后续生态动作和群体方向将直接接入这一底座。

## 任务额外说明

1. 当前程序化角色仍不算审美完成，但它们已经是正式生产线的一部分，而不是一次性占位。
2. 下一阶段重点不是“找外部角色资源替换”，而是把程序化轮廓、替身和表现分层做强。

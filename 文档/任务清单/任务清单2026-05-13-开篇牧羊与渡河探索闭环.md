# 任务清单 2026-05-13 - 开篇牧羊与渡河探索闭环

## 最终目标

1. 形成当前阶段的正式可玩竖切：牧羊人开局 -> 自然规律体验 -> 梦境 -> 征兆理解 -> 找到渡河办法 -> 穿过第一道自然边界。
2. 让玩家不依赖任务栏，也能明白“为什么要离开”“该观察什么”“如何真正过去”。
3. 复用现有程序化村庄、征兆、记事本、区域入口和展示验收底座，不引入违背愿景的显式任务系统。

## 主要任务1

### 1. 开篇牧羊人玩法闭环

- [ ] 把羊群从环境氛围升级为玩家可参与的开篇玩法对象，至少实现一条正式闭环：跟随、归圈、饮水、吃草或放牧。
- [ ] 建立“完成一次放羊/收羊”作为开篇 10 分钟自然教学的核心过程。
- [ ] 让牧羊行为、海边停留、与牧羊人/商人的接触共同影响离村相关意愿，而不是只靠时间推进。
- [ ] 让记事本自动记录第一批关于羊群、海风、村庄规律的见闻。

### 2. 梦境与离村动机强化

- [ ] 把梦境触发条件从纯时间推进升级为“时间 + 开篇生活体验”共同决定。
- [ ] 强化梦后优先征兆：鸟群方向、风向变化、占卜人、商人传闻。
- [ ] 让预兆在玩家长期无响应时减弱，在重新尝试离村时恢复。
- [ ] 保持 UI 非任务化，只保留记事本、方位感和征兆反馈，不引入目标箭头。

## 主要任务2

### 1. 第一条自然边界穿越闭环

- [ ] 在“迷雾河旧渡口”和“港口小船”中选择一条作为当前阶段第一条正式穿越路径，优先实现其中一条完整闭环。
- [ ] 把 `TransitionGate` 从“条件满足后可通过”升级为“线索发现 -> 条件满足 -> 穿越动作 -> 对岸到达”的实际流程。
- [ ] 让穿越前后的征兆、记事本、区域状态和展示样张完整记录下来。
- [ ] 让边界表现像世界的一部分，而不是功能性传送门。

### 2. 为城镇阶段预留落点

- [ ] 穿越完成后进入第一个城镇或集镇原型，而不是直接跳到沙漠。
- [ ] 为“挣钱准备”和“第一次损失”预留 `Journey`、`Director`、`Notebook` 和区域状态结构。
- [ ] 新增“梦后离村”“边界穿越”“对岸入口”三类正式展示样张。
- [ ] 完成与该竖切直接相关的测试、日志和性能验收。

## 任务额外说明

1. 这是当前项目的第一优先级主任务，现有天气、村庄、地表、生态、地标和展示专项都应作为支撑任务接入。
2. 如果只能先做一条路线，优先做“村庄 -> 迷雾河旧渡口 -> 对岸入口”，因为现有区域、征兆和生态骨架最接近。

# 任务清单 2026-05-12 - 地表材质与植被细节

## 最终目标

1. 把当前程序化地形从“能看出地貌”升级到“近看有质感、远看有层次”。
2. 建立草、灌木、石块、沙纹、河岸、湿地、雪面等程序化细节系统。
3. 让地表细节回应生物群系、天气、季节、征兆和玩家距离。

## 地表材质升级

### 1. 分层地表材质

- [ ] 为草甸、林地、旷野、山脊、沙丘、戈壁、绿洲、水岸建立独立材质层。
- [ ] 地表材质混合根据高度、坡度、湿度、河流、侵蚀和区域类型决定。
- [ ] 增加程序化纹理：草色噪声、碎石点、沙纹方向、湿岸边界、积雪变化。
- [ ] 近景材质需要有粗糙度和法线层次，避免纯色塑料感。

### 2. 天气影响

- [ ] 雨后增加湿地反光、泥土加深和水岸扩大。
- [ ] 沙暴时增加地表沙尘覆盖和远处对比度下降。
- [ ] 雪天增加高处和缓坡积雪，避免所有地表一起变白。
- [ ] 梦境或感知增强时，允许局部地表出现短暂的光、风、沙纹方向变化。

## 植被与散布物

### 1. 高频自然细节

- [ ] 草甸生成不同高度的草簇，并按风向轻微摆动。
- [ ] 林地生成灌木、树桩、落叶和根部隆起。
- [ ] 山脊生成碎石、裸岩、风蚀纹理和稀疏草。
- [ ] 沙漠生成沙脊、风滚痕、干灌木、碎陶或遗迹残片。

### 2. 生态与征兆关联

- [ ] 鸟群迁飞方向能与草浪或树梢风向形成一致的视觉线索。
- [ ] 羊群活动区域需要有被踩低的草、围栏周围裸土或路径痕迹。
- [ ] 河边、井边、绿洲周围的植被密度应自然升高。
- [ ] 征兆出现时，局部植物或沙纹可以形成微弱方向性，但不能像任务路线。

## 性能与展示

### 1. 细节 LOD

- [ ] 高频细节必须随距离降级：近景网格、中景批处理、远景材质噪声。
- [ ] 细节生成随地形分块加载和卸载，不能泄漏实体。
- [ ] 增加植被密度配置，用于性能回退。
- [ ] 展示模式增加“近景地表细节”和“沙丘风纹”两个镜头。

## 任务额外说明

1. 地表细节要让玩家愿意慢下来观察，而不是制造收集点。
2. 细节密度必须和性能报告绑定，不能只凭主观感觉调参。

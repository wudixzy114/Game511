# 任务清单 2026-05-12 - 村庄资产升级与生活氛围

## 最终目标

1. 把出生村庄建设成高质量、可停留、可回望、具有精神重量的正式开篇空间。
2. 村庄的正式路线必须是高质量程序化环境生成，而不是等待外部现成资产接管。
3. 村庄的风、湿度、海雾、炊烟、布棚、海岸、生活密度和梦后不安必须由统一氛围控制层驱动。

## 阶段定位

1. 本任务当前直接服务“牧羊人开局”和“梦后离村”，属于主任务的核心支撑战线。
2. 当前阶段优先做与羊圈、海边、外出小路、梦后风向变化直接相关的村庄质量升级。
3. 不允许把村庄审美专项无限展开，而主线玩法仍停留在纯场景浏览。

## 正式程序化村庄路线

### 1. 环境资产与程序化配方

- [x] 为房屋、水井、羊圈、集市、海边、路径石建立正式程序化资产锚点。
- [x] 将资产锚点语义从外部 `glb` 偏好路径纠偏为程序化配方路径。
- [x] 为房屋建立更高质量的程序化构造层：墙体、屋顶、门窗、梁柱、基础、落地关系。
- [ ] 为集市、羊圈、水井、海边建立更细的程序化构件层与材质层。

### 2. 统一氛围控制层

- [x] 建立 `VillageAtmosphere`，统一管理时间段、风强、风向、海雾、生活密度和梦后不安。
- [x] 让布棚摆动、烟、海边水纹开始读取统一氛围控制层，而不是继续各自做局部时间函数。
- [ ] 将统一氛围控制层继续接到材质湿润、脚印/踩踏、浅滩泡沫、暖窗强度和远景海雾。
- [ ] 建立梦前宁静 / 梦后不安 / 村外风向改变的完整状态图。

### 3. 审美质量推进

- [ ] 村庄黎明必须形成正式构图样张，而不是功能展示镜头。
- [ ] 海边需要连续的浅滩、湿沙、泡沫、雾幕和旧木构件关系。
- [x] 羊圈需要真实围栏结构、踩踏地、草料与内外空间层次。
- [x] 集市需要摊布、货物、悬挂物、容器和停留痕迹。

## 本轮进展

1. 新增统一村庄氛围控制层 `VillageAtmosphere`。
2. 新增村庄氛围日志输出，便于复盘当前风、海雾、生活密度和梦后不安状态。
3. 现有占位动效开始从环境快照和统一风场中读取输入，为后续高质量程序化升级铺底。
4. 房屋蓝图升级为分墙体、坡屋顶、门洞、开门板、梁柱、炉灶、床铺、桌子和室内灯的组合，不再是单一方块。
5. 村庄生成记录每栋房屋的门和室内锚点，`F` 可推门进入或离开屋舍。
6. 新增村庄碰撞代理，房屋、井、羊圈、摊位、NPC 和室内道具开始阻挡玩家胶囊体，房屋门洞保持可通行。

## 任务额外说明

1. 当前灰盒几何仍然存在，但它们的存在意义已经从“正式交付物”降级为“程序化高质量生产线的第一层底座”。
2. 村庄的正式完成标准是“让玩家愿意停留”，不是“看得出这里是村庄”。

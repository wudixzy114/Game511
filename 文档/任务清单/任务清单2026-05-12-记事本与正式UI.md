# 《道》任务清单：记事本与正式 UI（2026-05-12）

## 最终目标

1. 用记事本替代传统任务栏，记录梦境、对话、地点、征兆和回响。
2. 将正式 HUD 从开发调试信息中解放出来，保持极简体验。
3. 建立小地图、方向感、快速移动和临时物品栏的第一版规则。
4. 保证 UI 中文显示稳定、布局不遮挡、不任务化。

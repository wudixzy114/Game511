# 《道》任务清单：沙漠金字塔地标（2026-05-12）

## 最终目标

1. 实现第一张强主题远方地图：沙漠。
2. 实现沙暴中千米外可见轮廓的巨大金字塔地标。
3. 让沙漠拥有独特危险、资源和探索价值。
4. 将梦境、征兆、感知、记事本和沙漠地标绑定成完整体验。

## 主要任务1

### 1. 沙漠区域设计

- [ ] 使用 UTF-8 阅读 `文档/游戏介绍.md` 中沙漠、金字塔和地图吸引力相关描述。
- [ ] 明确沙漠的辩证关系：危险更强，探索价值也更高。
- [ ] 定义沙漠区域类型：沙丘、戈壁、绿洲、风蚀地、地下古城入口。
- [ ] 定义沙漠资源类型：水源、阴影、古物、稀缺材料。
- [ ] 定义沙漠危险类型：迷失、缺水预留、沙暴、视野降低、地形阻隔。
- [ ] 明确第一版只做表现和探索，不做复杂生存数值。

### 2. 沙漠地形生成

- [ ] 扩展地形采样，支持沙丘和戈壁倾向。
- [ ] 沙丘需要有连续起伏，不应像普通山地。
- [ ] 戈壁需要更硬、更平、更少植被。
- [ ] 绿洲需要水、湿度、植被和可识别轮廓。
- [ ] 地表材质扩展沙地、岩地、绿洲湿地。
- [ ] 沙漠散布物扩展枯木、岩柱、低矮灌木或风蚀石。
- [ ] 为沙漠采样和群系判定补充测试。

## 主要任务2

### 1. 巨大金字塔地标

- [ ] 新增区域级地标 `Landmark` 或沙漠地标模块。
- [ ] 使用程序化几何生成巨大金字塔。
- [ ] 金字塔需要支持远景轮廓和近景实体。
- [ ] 金字塔在沙暴或雾化空气中若隐若现。
- [ ] 金字塔位置由区域种子决定，但与梦境和旅程目标可绑定。
- [ ] 金字塔周边生成入口、台阶、残墙或地下古城入口占位。
- [ ] 为地标生成确定性补充测试。

### 2. 远景与 LOD

- [ ] 为金字塔提供远景 impostor 或简化 mesh。
- [ ] 确保远距离可见轮廓稳定，不闪烁、不突然弹出。
- [ ] 金字塔近景细节按距离逐步增加。
- [ ] 沙暴强时只露出轮廓，沙暴弱时显示更完整形体。
- [ ] 检查与现有地形 LOD、远景 impostor 的遮挡和层级关系。

## 主要任务3

### 1. 沙暴环境

- [ ] 新增沙暴天气类型或沙漠专属天气状态。
- [ ] 沙暴影响天空颜色、雾、能见度、粒子、风向和环境光。
- [ ] 沙暴中金字塔轮廓应成为强吸引点。
- [ ] 沙暴强度可随旅程阶段或感知状态变化。
- [ ] 沙暴表现不能严重破坏帧率。
- [ ] 沙暴关键参数接入配置。
- [ ] 为沙暴天气选择和强度混合补充测试。

### 2. 沙漠征兆与感知

- [ ] 梦境后，沙漠金字塔成为长期语义目标。
- [ ] 进入沙漠前，征兆可以通过风、鸟、商队传闻或梦中图像指向沙漠。
- [ ] 进入沙漠后，感知可以短暂让沙暴露出金字塔轮廓。
- [ ] 玩家迷失时征兆可以减弱或变得混乱。
- [ ] 玩家找到绿洲或高地时征兆重新清晰。
- [ ] 相关事件写入记事本。

## 主要任务4

### 1. 沙漠探索价值

- [ ] 生成至少一个绿洲。
- [ ] 生成至少一个地下古城入口占位。
- [ ] 生成至少一个稀缺资源或哲学物品占位。
- [ ] 每类探索点都需要语义标签，供旅程、征兆和记事本使用。
- [ ] 探索点不显示任务目标。
- [ ] 与村庄、商人或梦境建立传闻/回响联系。

### 2. 展示模式

- [ ] 新增“沙漠金字塔展示”。
- [ ] 展示覆盖：沙丘、戈壁、绿洲、沙暴、远景金字塔、近景金字塔、感知增强。
- [ ] 展示应有固定镜头路径，便于检查远近 LOD 和沙暴效果。

## 主要任务5

### 1. 验证与性能

- [ ] 运行 `cargo fmt --all --check`。
- [ ] 运行 `cargo test`。
- [ ] 运行 `cargo clippy --all-targets -- -D warnings`。
- [ ] 运行探索模式和展示模式自动退出验证。
- [ ] 沙暴和金字塔属于重型视觉系统，按 `AI开发流程.md` 采集性能 baseline、优化后采样和 compare。
- [ ] 检查金字塔远景没有明显闪烁、遮挡错误或严重弹出。

## 任务额外说明

沙漠金字塔是验证《道》地图吸引力的关键样板。它必须是玩家自然想去的地方，而不是任务要求玩家去的地方。

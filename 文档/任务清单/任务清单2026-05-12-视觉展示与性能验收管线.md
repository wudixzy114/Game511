# 任务清单 2026-05-12 - 视觉展示与性能验收管线

## 最终目标

1. 建立“画面改动必须可展示、可截图、可回放、可性能对比”的验收流程。
2. 避免视觉迭代只凭终端输出或主观印象判断。
3. 让 3A 方向的追求变成一批可持续通过的质量门槛。

- [x] 展示模式新增固定矩阵：村庄黎明、梦后村外、迷雾边界、沙暴金字塔、绿洲废墟、夜空海边。

## 性能验收

### 1. 性能基准

- [x] 为视觉展示矩阵建立 baseline 性能日志。
- [x] 新增资产、粒子、植被、天气后必须运行 `.\scripts\perf.ps1`。
- [x] 优化后运行 `.\scripts\perf.ps1 -Action compare`。
- [x] 性能结论必须说明平均帧耗时、p95、p99、超预算帧和主要瓶颈阶段。

2026-05-12 本轮性能采样：`.\scripts\perf.ps1 -Seconds 12` 与 `.\scripts\perf.ps1 -Action compare` 已运行。compare 结果：平均帧耗时 24.13ms -> 22.63ms，p95 28.26ms -> 24.99ms，p99 246.28ms -> 52.07ms，超预算帧 79 -> 473（采样帧数 104 -> 531），world_streaming 平均 0.19ms -> 0.10ms，environment 平均 0.63ms -> 0.58ms。候选报告仍为 p95 超预算，并提示 `low instrumentation coverage`，当前埋点仅解释 3.9% 平均帧耗时。

### 2. 质量门槛

- [ ] 所有新增重型视觉系统接入 `FramePerformance`。
- [x] 如果性能报告提示埋点覆盖不足，先补埋点再下结论。
- [x] 视觉质量回退选项必须配置化：粒子密度、植被密度、细节距离、阴影或雾强度。
- [ ] 不能为了性能完全移除关键地标或核心征兆表现，应优先降级 LOD。

2026-05-12 本轮新增回退项：`[world] detail_density` 控制地表散布密度，`[ecology] sheep_count`、`max_visible_fish_distance`、`max_visible_sheep_distance` 控制生态角色表现预算。因性能报告仍提示埋点覆盖不足，后续应补充渲染准备/启动系统/子部件动画阶段埋点后再做全局瓶颈结论。

## 任务额外说明

1. 展示与性能管线是所有视觉任务的共同验收入口。
2. 文档、截图、日志和性能报告要共同判断质量，单独看任何一种都不够。
3. 收尾前通常运行 `cargo fmt --all --check`、`cargo test`、`cargo clippy --all-targets -- -D warnings`。

# 《道》任务清单：村庄开篇与梦境（2026-05-12）

## 最终目标

1. 将玩家出生体验从“直接进入野外”升级为“出生在宁静村庄”。
2. 建立可以停留、生活、观察和互动的第一处人间场所。
3. 实现数日后梦见金字塔下宝藏的硬编码开篇剧情。
4. 让梦境成为后续征兆、感知和多地图旅程的起点。

### 1. 设计与现状对齐

- [x] 使用 UTF-8 阅读 `文档/游戏介绍.md` 和 `文档/系统总设计方案.md`。
- [x] 阅读现有 `src/game/world.rs`、`src/game/places.rs`、`src/game/journey.rs`、`src/game/ui.rs`，确认可复用边界。
- [x] 明确村庄开篇不是传统新手任务，不显示任务目标。

- [x] 在设计说明中记录村庄开篇与现有短旅程闭环的衔接方式。

### 2. 村庄区域生成

- [x] 新增村庄区域状态或地点集合，避免直接把村庄硬塞进普通意义地点。
- [x] 生成出生点，保证玩家起始位置在可行走平坦地面。
- [x] 生成至少 5 类村庄标志：房屋、羊圈、水井、集市摊位、海边/岸线。
- [x] 使用程序化 mesh 和材质，不依赖外部美术资产。
- [x] 村庄布局需要保持确定性，同一世界种子下结果一致。
- [x] 村庄周边与现有地形自然衔接，避免房屋悬空、埋入地下或出现在水下。
- [x] 为村庄生成逻辑补充单元测试或可重复检查函数。

## 主要任务2

### 1. 村庄 NPC 与动物占位

- [x] 新增第一批村庄实体类型：羊、牧羊人、商人。
- [x] 羊群具备简单群体游走，活动范围限制在羊圈和附近草地。
- [ ] 牧羊人具备基础日程：靠近羊群、停留、回到村庄。
- [x] 商人具备基础日程：停留在摊位、短距离走动、面向玩家。
- [x] NPC 和动物状态不需要完整 AI，但必须通过组件结构为行为树预留扩展点。
- [x] 实体进入游戏时生成，退出游戏或返回主菜单时清理。
- [x] 为关键行为状态补充纯逻辑测试。

### 2. 轻交互

- [x] 支持玩家靠近 NPC 或动物时触发非任务化提示。
- [x] 支持与商人或牧羊人进行第一版短对话。
- [x] 对话内容应服务世界观和氛围，不给出任务清单。
- [x] 支持与羊群的轻互动或观察记录。
- [x] 交互结果可写入旅程记忆或后续记事本接口。

## 主要任务3

### 1. 时间推进与村庄停留

- [x] 在旅程系统中新增开篇阶段：村庄醒来、村庄生活、梦境将至、梦后回响。
- [x] 支持以游戏内天数或时间片记录玩家在村庄中的停留。
- [x] 玩家可以一直停留，不强制离开村庄。
- [x] 当玩家多次接近海边、羊群、商人或村外路径时，记录不同倾向。
- [x] 长时间无推进时，世界只通过氛围变化提示，不弹任务目标。

### 2. 梦境系统第一版

- [x] 新增 `DreamState` 或旅程梦境子状态。

- [x] 梦境可以先用环境、相机、光影、文本或短暂场景切换表现。
- [x] 梦境结束后回到村庄，记录梦后回响。
- [x] 梦境触发、结束、回响写入日志。

## 本轮实现说明

2026-05-12 本轮新增 `src/game/village.rs`、`src/game/intent.rs`、`src/game/notebook.rs`，并接入 `journey`、`signs`、`ui`、`presentation`。村庄与现有意义地点并行存在：村庄负责开篇生活空间，原有意义地点继续负责短旅程闭环。梦境作为长线 `StoryArcStage` / `DreamState` 推进，不显示任务目标；梦后通过意愿、感知和 `SignState` 增强已有征兆表达。

## 任务额外说明

本阶段重点是建立“可以不出发，但最终会被内心召唤”的开篇体验。所有实现都要避免新手任务化，梦境和征兆只提供世界回应，不提供传统任务目标。

# 性能工具使用说明

## AI 首选入口

需要性能诊断时，AI 默认直接运行：

```powershell
.\scripts\ultimate-profile.ps1
```

默认行为：

- 运行 30 秒 `presentation` 模式。
- 同时采集 `logs/performance.log` 和 Tracy trace。
- 默认保留最新 2 组最终结果，自动删除 CSV、子报告、日志快照等中间文件，可用 `-ResultKeep 2` 调整。
- 输出给 AI 看的 Markdown：`logs/ultimate/ultimate-<timestamp>-ai.md`。
- 输出给人看的网页：`logs/ultimate/ultimate-<timestamp>-report.html`。
- 保留当前原始数据：`logs/performance.log` 和 `logs/tracy/ultimate-<timestamp>.tracy`。

常用命令：

```powershell
.\scripts\ultimate-profile.ps1
.\scripts\ultimate-profile.ps1 -Seconds 30 -GameMode exploration -Top 15
.\scripts\ultimate-profile.ps1 -KeepIntermediates
```

AI 读取顺序：

1. 先读 `logs/ultimate/*-ai.md`。
2. 再看 `logs/ultimate/*-report.html`。
3. 若要继续深挖，打开 `logs/tracy/*.tracy`。
4. 不要只凭单次 Tracy 结论宣布优化有效；优化后必须回到 `perf.ps1` 做前后对比。

## 性能优化验证流程

只要任务涉及性能优化，最终必须用 `perf.ps1` 做前后对比：

```powershell
.\scripts\perf.ps1 -Seconds 12
# 修改代码
.\scripts\perf.ps1 -Seconds 12
.\scripts\perf.ps1 -Action compare
```

最终回复必须汇报：

- 平均帧耗时变化。
- p95 / p99 变化。
- 超预算帧数变化。
- 主要瓶颈阶段变化。
- 是否出现 `low instrumentation coverage`。

如果数据没有改善，必须明确说明“本次优化未被性能数据验证有效”。

## 专项工具

交互式 Tracy：

```powershell
.\scripts\profile.ps1 -Mode tracy -Seconds 12 -GameMode presentation
```

离线 Tracy 自动分析：

```powershell
.\scripts\profile.ps1 -Mode tracy-analyze -Seconds 12 -GameMode presentation
.\scripts\profile.ps1 -Mode tracy-analyze -Trace .\logs\tracy\some.tracy -Top 12
```

说明：

- `tracy-analyze` 默认删除 CSV 中间文件。
- 需要保留 CSV 时加 `-KeepCsv`。
- 自动捕获的 `.tracy` 默认只保留最新 2 个，可用 `-TraceKeep 2` 调整。

## 常用 perf 命令

```powershell
.\scripts\perf.ps1
.\scripts\perf.ps1 -Action report
.\scripts\perf.ps1 -Action compare
.\scripts\perf.ps1 -Action html
.\scripts\perf.ps1 -Action report -Json
```

## 配置

`config/app.toml`：

```toml
performance_detail_interval = 1
frame_log_interval = 120
```

含义：

- `performance_detail_interval = 1`：每帧记录细粒度样本，适合性能分析。
- `performance_detail_interval = 0`：关闭逐帧细节样本。
- `frame_log_interval`：普通帧日志输出间隔，不影响细粒度 HTML 报告。

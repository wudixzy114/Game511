# 性能工具使用说明

## 目标

当前性能工具覆盖三类使用场景：

- 细粒度查询：逐帧记录 `frame_detail`，报告中提供 `p50/p90/p95/p99/stddev` 和各阶段平均、p95、p99、max。
- 对比查询：支持直接对比两个日志，也支持一键对比最近两次性能快照。
- 可视化展示：可生成独立 HTML 报告，包含帧时间趋势、阶段均值对比和阶段明细表。

## 采集一次性能样本

```powershell
.\scripts\perf-capture.ps1 -Seconds 8
```

脚本会：

- 设置 `DAO_AUTO_EXIT_SECONDS`
- 设置 `DAO_AUTO_START_MODE=presentation`，自动跳过主菜单进入游戏展示场景
- 自动运行游戏并退出
- 把 `logs/performance.log` 快照保存为 `logs/performance.<timestamp>.log`
- 自动打印本次性能报告

可切换为第一人称探索模式：

```powershell
.\scripts\perf-capture.ps1 -Seconds 8 -Mode exploration
```

## 一键后台采集并生成 HTML

```powershell
.\scripts\perf-auto-html.ps1 -Seconds 12
```

脚本会自动完成：

- 归档运行前的 `logs/performance.log` 作为 baseline
- 设置 `DAO_AUTO_START_MODE`，跳过主界面直接进入游戏
- 设置 `DAO_AUTO_EXIT_SECONDS`，到时间自动退出
- 保存本次运行日志快照
- 生成 `logs/performance-report.html`

指定探索模式：

```powershell
.\scripts\perf-auto-html.ps1 -Seconds 12 -Mode exploration
```

## 查询单个日志

```powershell
cargo run --bin perf_report -- .\logs\performance.20260512-010203.log
```

JSON 输出：

```powershell
cargo run --bin perf_report -- --json .\logs\performance.20260512-010203.log
```

## 对比两个日志

```powershell
cargo run --bin perf_report -- .\logs\baseline.log .\logs\candidate.log
```

## 一键对比最近两次

```powershell
.\scripts\perf-compare-latest.ps1
```

等价命令：

```powershell
cargo run --bin perf_report -- compare-latest .\logs
```

## 生成 HTML 可视化报告

对比指定两个日志：

```powershell
cargo run --bin perf_report -- html .\logs\performance-report.html .\logs\baseline.log .\logs\candidate.log
```

对比最近两次：

```powershell
.\scripts\perf-html-latest.ps1
```

生成的报告默认位于：

```text
logs/performance-report.html
```

## 配置项

`config/app.toml` 中新增：

```toml
performance_detail_interval = 1
```

含义：

- `1`：每帧记录一次细粒度样本，适合做性能差异分析。
- `2` 或更大：按间隔降采样，降低日志写入量。
- `0`：关闭 `frame_detail` 细粒度样本。

保留原有配置：

```toml
frame_log_interval = 120
```

它控制普通 `frame` 信息日志的输出间隔，不影响 `frame_detail` 的细粒度报告能力。

## 自动启动环境变量

```powershell
$env:DAO_AUTO_START_MODE = "presentation"
cargo run
```

可选值：

- `presentation`：自动进入展示场景，适合无人值守性能采集。
- `exploration`：自动进入第一人称探索模式。
- `menu` / `off` / `false`：保留主菜单。

旧的 `DAO_PRESENTATION_MODE=1` 仍兼容，但推荐新脚本和 `DAO_AUTO_START_MODE`。

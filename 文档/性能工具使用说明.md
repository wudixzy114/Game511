# 性能工具使用说明

## 主要命令

日常只需要记一个入口：

```powershell
.\scripts\perf.ps1
```

默认行为：

- 自动跳过主菜单，进入 `presentation` 展示模式。
- 运行 12 秒后自动退出。
- 保存本次性能日志快照。
- 生成 `logs/performance-report.html`。

常用选项：

```powershell
.\scripts\perf.ps1 -Seconds 20
.\scripts\perf.ps1 -Mode exploration
.\scripts\perf.ps1 -Output .\logs\my-report.html
```

## 其它动作

只采集并打印报告：

```powershell
.\scripts\perf.ps1 -Action capture -Seconds 10
```

查看某个日志：

```powershell
.\scripts\perf.ps1 -Action report -Log .\logs\performance.log
```

对比最近两次日志：

```powershell
.\scripts\perf.ps1 -Action compare
```

对比指定两个日志：

```powershell
.\scripts\perf.ps1 -Action compare -Baseline .\logs\old.log -Candidate .\logs\new.log
```

只生成 HTML：

```powershell
.\scripts\perf.ps1 -Action html -Baseline .\logs\old.log -Candidate .\logs\new.log
```

输出 JSON：

```powershell
.\scripts\perf.ps1 -Action report -Log .\logs\performance.log -Json
```

## 瓶颈诊断能力

报告会直接输出 `bottlenecks` / `candidate_bottlenecks`，用于回答“瓶颈在哪里”：

- 帧预算问题：p95 是否超过 `frame_time_budget_ms`。
- 尖峰问题：p99 和 p50 差距是否过大。
- 主热点阶段：哪个阶段占据最多已埋点耗时。
- 尖峰阶段：哪个阶段 p99 明显高于平均值。
- 埋点覆盖率：已埋点阶段能解释多少平均帧时间。

目前能定位到阶段级瓶颈：

- `world_streaming`
- `world_collision`
- `world_impostor`
- `world_visibility`
- `player`
- `ui`
- `environment`
- `presentation`
- `signs`

如果报告提示 `low instrumentation coverage`，说明仍有较多帧时间不在这些阶段里，需要继续给渲染准备、资源加载、启动流程或新系统补充埋点。这个提示很重要，它能避免误把“已埋点里最慢的阶段”当成真实全局瓶颈。

## 配置

`config/app.toml`：

```toml
performance_detail_interval = 1
frame_log_interval = 120
```

含义：

- `performance_detail_interval = 1`：每帧记录细粒度样本，最适合性能分析。
- `performance_detail_interval = 0`：关闭逐帧细节样本。
- `frame_log_interval`：普通帧日志输出间隔，不影响细粒度 HTML 报告。

自动启动由脚本设置：

```powershell
$env:DAO_AUTO_START_MODE = "presentation"
$env:DAO_AUTO_EXIT_SECONDS = "12"
```

可选模式：

- `presentation`：自动展示场景，适合无人值守性能采集。
- `exploration`：第一人称探索模式。
- `menu` / `off` / `false`：保留主菜单。

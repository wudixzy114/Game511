# 《道》任务清单：地形流式性能优化（2026-05-11）

## 阶段目标

1. 消除大型开放世界地形加载时的秒级卡顿。
2. 继续完善程序化地形生成链路，使分块加载具备可调预算、稳定帧时间和更低资源 churn。

## 任务项

### 1. 流式加载性能

- [x] 将新可见分块改为进入待生成队列，不在可见范围变化时同步全部生成。
- [x] 增加每帧地形分块生成预算配置，避免单帧 CPU 尖峰。
- [x] 启动时只生成玩家附近关键分块，其余可见分块按距离逐帧补齐。

### 2. 单分块生成成本

- [x] 复用树林、草簇、石块和山脊尖塔 mesh，避免每个散布物新建网格资产。
- [x] 优化分块网格构建中的高度采样，避免每个顶点重复多次执行地形噪声。
- [x] 保持河流、侵蚀、群系和法线在分块边界上的确定性。

### 3. 验证与文档

- [x] 补充测试覆盖分块队列去重、可见范围裁剪和预算配置解析。
- [x] 更新配置说明和系统设计，记录地形流式性能策略。
- [x] 运行格式化、编译、测试、clippy 和启动烟雾验证。

## 完成记录

- 地形加载已从同步批量生成改为 `TerrainStreamingQueue` 队列，每帧按 `streaming_chunk_budget` 处理。
- 启动阶段只同步生成玩家所在关键分块，其余可见分块按距离排序后逐帧补齐。
- 地表散布物改为共享 `DetailMeshes`，运行时只创建实体和缩放变换，不再为每个散布物创建新 mesh。
- 单分块网格构建改为先缓存本分块高度场，再由邻域高度计算坡度、法线和群系，减少重复地形噪声采样。
- 已通过 `scripts/dev-check.ps1` 和 `DAO_AUTO_EXIT_SECONDS=1.0 cargo run` 验证。

# 《道》任务清单：环境视觉效果（2026-05-11）

## 最终目标

1. 建立可扩展的自然环境视觉系统，覆盖太阳、月亮、大气、天气、粒子和星空。
2. 按项目流程提供可重复播放的展示模式，方便单独检查视觉效果。

## 主要任务1

### 1. 天空与天体

- [x] 实现太阳东升西落的方向、亮度、颜色与可见圆盘。
- [x] 实现夜间月亮、月光方向光与昼夜过渡。
- [x] 实现星空散布、夜间可见度和轻微闪烁变化。

### 2. 大气与天气

- [x] 接入基于相机的距离雾和大气散射色调。
- [x] 建立晴天、薄雾、降雨、暴风雨、降雪的天气状态。
- [x] 为不同天气提供雾色、可视距离、环境光、太阳/月亮遮蔽和风向差异。
- [x] 实现雨、雪、雾粒子，并加入暴风雨闪电光效。

## 主要任务2

### 1. 展示集成

- [x] 扩展展示导演，按固定场景演示晴天全景、薄雾树林、山脊日出、暴风雨、降雪山脊、星空和月光水面。
- [x] 修正展示模式环境变量入口，确保 `DAO_PRESENTATION_MODE` 能强制进入展示模式。
- [x] 保持环境视觉系统独立于地形和征兆系统，后续可以继续扩展天气规则。

### 2. 质量验证

- [x] 为天气序列、太阳东西方向、天气混合和闪电强度补充测试。
- [x] 运行格式化、编译、测试、Clippy 与展示模式启动烟雾验证。

## 任务额外说明

本阶段采用程序化网格和材质实现视觉原型，不依赖外部美术资产。天气粒子目前是轻量级网格实例方案，后续可以在视觉确认后升级为 GPU 粒子或专用材质。

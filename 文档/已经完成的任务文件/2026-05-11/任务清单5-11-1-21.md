# 《道》独立游戏任务清单

## 最终目标

1. 搭建一个基于 Bevy 的高质量 3D 开放世界原型工程，具备程序化世界、征兆系统、日志、性能检测与测试基础设施。
2. 形成与游戏愿景一致的系统总设计方案，为后续世界规律、AI 叙事和高质量视觉迭代提供稳定起点。

## 主要任务1

### 1. 工程与环境搭建

- [x] 初始化 Rust 二进制工程并建立 `src/core` 与 `src/game` 模块边界。
- [x] 配置 Bevy、序列化、日志与错误处理依赖。
- [x] 增加 `config/app.toml` 与 `.cargo/config.toml`，固定基础运行参数与无警告编译要求。
- [x] 预留脚本目录，便于后续自动化构建与资源处理扩展。

### 2. 基础运行骨架

- [x] 创建应用入口 `build_app()`，统一加载核心插件与游戏插件。
- [x] 搭建 3D 摄像机、光照、程序化地形块、水面与角色原型。
- [x] 将世界种子、窗口标题、质量预算等配置注入运行时资源。

## 主要任务2

### 1. 质量基础设施

- [x] 建立分层日志系统，输出应用日志、错误日志与性能日志。
- [x] 建立逐帧性能采样与预算告警机制。
- [x] 为配置、性能、程序化世界和征兆状态编写单元测试。
- [x] 将编译告警提升为错误，保证每次检查必须清洁通过。

### 2. 设计与文档

- [x] 阅读游戏介绍、质量要求、开发流程和设计模板。
- [x] 编写面向当前阶段的系统总设计方案。
- [x] 形成任务清单，记录已完成内容与后续优先级。

## 任务额外说明

当前交付聚焦“高质量可扩展原型底座”，不是完整游戏内容实现。世界规律、AI 独家历险、行为树生态和高保真渲染链路已在结构上留出扩展点，但仍需进入下一轮专项开发。

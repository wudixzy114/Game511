# 《道》任务清单：地形分块缓存与复用（2026-05-11）

## 阶段目标

1. 在已有分帧流式生成基础上，避免玩家往返移动时重复生成同一地形分块。
2. 为大型开放世界长期探索建立可控内存占用的地形缓存策略。

## 任务项

### 1. 分块缓存

- [x] 增加地形分块 mesh 缓存，重新进入可见范围时直接复用已有 mesh handle。
- [x] 增加分块散布布局缓存，避免重复计算同一分块的草、树、石块和尖塔位置。
- [x] 保持缓存结果和世界种子、地形规则完全确定。

- [x] 增加配置项控制缓存容量。
- [x] 实现不淘汰当前可见分块的 LRU 风格淘汰。
- [x] 淘汰时同步移除不再保留的 mesh 资产。

### 3. 验证与文档

- [x] 补充测试覆盖缓存复用、缓存淘汰和配置解析。
- [x] 更新工具说明和系统设计文档。

## 完成记录

- 新增 `TerrainChunkCache`，缓存每个分块的 terrain mesh handle 和散布布局。
- 新增 `streaming_cache_capacity` 配置，默认允许保留 192 个流式分块缓存。
- 重新进入视野的分块会直接复用缓存，不再重复执行分块网格构建和散布布局计算。
- 缓存淘汰会跳过当前可见分块，并移除对应 mesh 资产，控制长期探索时的内存增长。
- 已通过 `scripts/dev-check.ps1` 和 `DAO_AUTO_EXIT_SECONDS=1.0 cargo run` 验证。

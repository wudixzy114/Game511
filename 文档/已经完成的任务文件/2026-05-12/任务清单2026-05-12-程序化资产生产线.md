# 任务清单 2026-05-12 - 程序化资产生产线

## 最终目标

1. 建立统一的程序化资产生产线，避免村庄、地标、生态、地表细节各自临时生成几何体。
2. 让程序化资产具备语义、LOD、材质、碰撞、展示和征兆绑定能力。
3. 用代码优先的方式，为后续接近 3A 的画面迭代提供稳定基础。

## 资产语法与注册表

### 1. 建立资产描述结构

- [x] 设计 `ProceduralAssetSpec`：记录资产类型、语义标签、种子、尺寸、材质族和 LOD 策略。
- [x] 设计 `ProceduralAssetRegistry`：集中注册房屋、树、岩石、草、遗迹、动物、NPC、地标部件。
- [x] 资产必须能通过稳定种子复现，方便截图、性能和 bug 复盘。
- [x] 资产语义必须能被征兆、感知、记事本和导演查询。

2026-05-12 本轮完成 `src/game/assets.rs` 第一版：新增 `ProceduralAssetSpec`、`ProceduralAssetRegistry`、`ProceduralAsset` 组件、资产类型、语义标签、材质族、LOD 策略、碰撞语义和稳定种子/ID。当前已注册村庄房屋、水井、羊圈、集市、海岸、路石、羊、牧羊人、商人、鸟、鱼、占卜人、沙漠金字塔、绿洲、遗迹墙、古物、迷雾河和海岬标记。

### 2. 统一生成入口

- [x] 把直接散落在系统里的简单 `Cuboid` / `Capsule` 占位逐步迁移到资产工厂。
- [x] 提供近景网格、中景简化、远景 impostor 三档生成接口。
- [x] 生成接口必须返回实体根节点，便于统一清理、隐藏、LOD 切换和性能统计。
- [x] 资产生成失败必须记录日志，不能静默缺失。

2026-05-12 本轮完成第一步迁移：暂不重写网格生成路径，但已经给村庄、地标和生态的首批现有实体挂载统一 `ProceduralAsset` 组件。`dao_game::assets::runtime` 会在运行时记录资产数量、资产类型数量和语义数量，作为后续迁移资产工厂前的观测入口。

2026-05-12 本轮继续完成统一资产工厂落地：`src/game/assets.rs` 新增 `ProceduralAssetMaterials`、`ProceduralSpawnRequest`、`ProceduralAssetLod`、`ProceduralAssetBlueprint` 和 `spawn_procedural_asset(_entity)`。村庄、地标和生态首批可见资产已从各系统本地网格拼装迁移到资产工厂，根实体统一携带 `ProceduralAsset`，子部件由蓝图生成。近景/中景/远景蓝图已覆盖全部注册资产，空蓝图会写入 `dao_game::assets::factory` 错误日志。

# 《道》任务清单：多地图与自然边界（2026-05-12）

## 最终目标

1. 将当前单张连续开放世界升级为多区域世界架构。
2. 通过河流、迷雾、高山、海洋、渡口、山口等自然边界连接地图。
3. 避免玩家从一张地图直接看穿到另一张地图。
4. 为村庄到沙漠、山后地图、远海小岛等后续旅程打底。

- [x] 使用 UTF-8 阅读 `文档/游戏介绍.md` 中“地图”部分。

- [x] 设计 `TransitionGate`，描述迷雾河、山口、港口、洞穴等自然过渡点。
- [x] 明确当前 `WorldMap` 如何作为单区域地形采样器被复用。

### 2. 区域类型第一版

- [x] 第一版至少实现村庄海岸、山地边界、沙漠三个区域定义。

## 主要任务2

### 1. 自然边界实现

- [x] 实现迷雾河边界原型。
- [x] 实现山脉或山口边界原型。
- [x] 实现海岸/远海边界原型。
- [x] 边界应在视觉上自然，不像空气墙。
- [x] 第一版可以阻挡玩家，但必须提供可被征兆或后续能力解释的通过条件。
- [x] 边界状态写入日志，便于调试玩家为何无法通过。

### 2. 过渡条件

- [x] 定义过渡条件类型：找到渡口、造船、翻越山口、跟随 NPC、完成梦后意愿。
- [x] 第一版至少实现一个可通过边界，例如迷雾河渡口或山口。
- [x] 过渡条件不显示任务清单，只通过记事本和征兆暗示。
- [x] 过渡前保存当前区域旅程状态。
- [x] 过渡后加载目标区域并放置玩家到合理入口。
- [x] 为过渡条件判定补充单元测试。

## 主要任务3

- [x] 抽象当前世界生成入口，使其能根据当前区域配置生成地形。
- [x] 区域切换时清理当前区域实体：地形、地点、NPC、动物、天气特效。
- [x] 区域切换时保留全局状态：长期旅程、记事本、梦境、玩家已知地点。
- [x] 区域切换时重建碰撞代理和流式缓存。
- [x] 区域切换期间避免明显卡死，必要时使用过渡遮罩、梦境、迷雾或加载状态。

### 2. 视觉遮挡与新鲜感

- [x] 使用山脉、雾、海平线、天气和距离控制避免看穿下一张地图。
- [x] 远景 impostor 需要按区域边界裁剪或替换。
- [x] 沙漠金字塔可在梦境或沙暴间隙中出现，但不应从村庄直接完整可见。
- [x] 边界附近的天气和地貌需要自然过渡。
- [x] 为边界可见性建立展示场景。

- [x] NPC 可提供非任务化传闻，例如“雾散时有人见过旧渡口”。
- [x] 区域切换后旅程导演更新候选地点和征兆。

### 2. 展示模式

- [x] 新增“多地图与自然边界展示”。
- [x] 展示覆盖：当前区域、自然边界、感知线索、通过边界、目标区域出现。
- [x] 展示可重复，不依赖随机玩家行为。

## 本轮实现说明

2026-05-12 本轮新增 `src/game/regions.rs`，建立 `WorldRegion`、`RegionGraphState` 和 `TransitionGate`。区域第一版包含村庄海岸、草原林地、山地边界、沙漠、远海；边界包含迷雾旧渡口、山口和港口。边界通过梦后回响、意愿、感知状态和自然提示开放，不显示任务目标；通过 `G` 在近距离跨越边界时保留全局旅程状态并把玩家放到目标区域入口。完整按区域重建地形流式缓存仍留到后续。
2026-05-12 本轮继续让意愿系统读取 `RegionGraphState.nearest_gate`：玩家靠近或停留在迷雾旧渡口、山口、港口附近时，会记录向村外、向山、向海或梦中地标的过渡意愿，边界开放时权重更强，但仍不显示任务路线。

多地图不是简单传送，也不是关卡列表。边界必须是世界的一部分，玩家应感觉自己通过了河、山、雾、海，而不是点击了菜单。

# 《道》系统总设计方案

更新时间：2026-05-13

## 1. 文档目的

本文档用于统一《道》的最终目标、系统路线和当前开发优先级，并明确一件事：

《道》的正式目标不是做一个“能跑的原型 + 后续等外部美术补齐”的项目，而是直接建设一个以程序化高质量表现为主、以世界规律和征兆旅程为核心、向 3A 质量追求的开放世界游戏。

本文档重点回答：

1. 《道》最终要成为什么。
2. 当前项目真正缺的是什么。
3. 为什么程序化生成不是妥协，而是正式路线。
4. 接下来应该按什么顺序大规模推进开发。

## 2. 当前总体判断

### 2.1 核心目标理解

《道》不是传统任务驱动开放世界，也不是靠数值、装备和刷取构成循环的游戏。它的核心体验是：

1. 玩家在一个有规律的世界里生活、停留、注视、迷失、感知。
2. 世界通过自然现象、动物行为、人物传闻、天气变化、梦境回响和远方地标给予征兆。
3. 玩家逐渐理解自己的真实意愿，并主动走向内心要去的地方。
4. 最终宝藏不是奖杯，而是旅程本身和返回出发点时的理解。

### 2.2 当前项目本质

当前项目已经不是空工程，也不是只有几个零散 demo。它已经具备：

1. 程序化地形、流式加载、LOD、缓存和碰撞代理底座。
2. 村庄开篇、梦境、意愿、感知、记事本、区域切换和沙漠地标原型。
3. 第一/第三人称、展示模式、性能报告、日志报告和基本导演接口。
4. 程序化资产注册与蓝图工厂的第一版能力。

因此，现在的主要矛盾已经不是“功能没有”，而是：

1. 画面仍偏原型化，缺少高质量、可持续的程序化表现体系。
2. 程序化资产虽然存在，但还没被提升为正式视觉语言。
3. 环境、天气、村庄、生态、地标的表现控制还没有完全统一到底座层。
4. 任务与设计文档里还残留“外部真实资产接入才是正式路线”的错误倾向。

### 2.3 本次重构的根本结论

必须明确：

1. 程序化生成不是低配替代，不是临时过渡，不是“等以后再换”的灰盒生产线。
2. 高质量程序化资产、高质量程序化材质、高质量程序化气氛、高质量程序化替身，必须成为《道》的正式路线。
3. 如果程序化生成难，就应继续攻克，而不是降低表现目标。
4. 《道》不要求极度写实，但必须高质量、可信、有尺度、有构图、有氛围，并让玩家愿意停留。

## 3. 系统总清单

## 3.1 世界规律系统

### 目标

建立一个由地形、群系、水系、天气、昼夜、边界、生态和地标共同构成的连续世界，而不是一个任务地图容器。

### 当前状态

已完成第一层底座，并具备继续扩展的基础。

### 已覆盖内容

1. 程序化高度场、湿度、温度、坡度、侵蚀、沉积、河流与群系。
2. 地形分块流式、后台生成、缓存、LOD、远景 impostor 与碰撞代理。
3. 多区域世界、自然边界、迷雾渡口、山口、港口和区域切换第一版。

### 后续余项

1. 区域间环境差异要进一步增强到“远看一眼就知道是哪里”。
2. 地形与地标的构图关系要更强，尤其是村庄、边界、沙漠、绿洲、金字塔。
3. 地形细节、地表材质、沙丘方向、湿岸层次和风蚀结构要继续提升。

## 3.2 程序化资产生产线

### 目标

把程序化资产从“能生成占位物”提升为《道》的正式视觉语法。

### 当前状态

已经建立注册表、蓝图工厂、语义标签、LOD 策略和多类资产蓝图，但表现质量仍在第一阶段。

### 已覆盖内容

1. `ProceduralAssetSpec`、`ProceduralAssetRegistry`、`ProceduralAssetBlueprint`、`ProceduralAssetFactory` 风格的基础结构已经形成。
2. 村庄、生态、地标、边界等核心资产已经具备程序化类型定义和基础蓝图。
3. 本轮重构已将资产锚点的偏好路径从外部 `glb` 语义纠偏为程序化配方路径，明确正式路线是程序化配方，而不是外部资源文件。

### 后续余项

1. 程序化资产族需要继续细化到构型层、材质层、语义层、动画层、LOD 层、展示层。
2. 近中远三档蓝图差异仍需增强，避免中远景继续退化成玩具化几何。
3. 村庄建筑、生态角色、地标巨构、边界部件都要提升轮廓和材料说服力。

## 3.3 环境、天气与统一风场系统

### 目标

让天空、风、雾、雨、雪、沙、海雾和梦后气氛成为世界规律与征兆的一部分，而不是孤立特效。

### 当前状态

已有完整天气循环、天空、昼夜、粒子和雾；本轮新增统一环境快照和统一风场底座。

### 已覆盖内容

1. 晴、雾、雨、暴风雨、沙暴、雪六种天气基本可运行。
2. 天空、太阳、月亮、星空、雾、闪电和天气粒子已接通。
3. 本轮新增 `EnvironmentSnapshot`，统一暴露天气、可见度、湿度、雾密度、云量、海雾、沙暴权重等状态。
4. 本轮新增 `WindField`，统一暴露风向、风速、阵风、旋涡和征兆偏置，供其他系统复用。

### 后续余项

1. 统一风场要继续接入生态、地表摆动、沙丘风纹和地标显隐。
2. 天空层次、区域色彩基准、体积氛围和云带还需要继续向高质量推进。
3. 雨、雪、沙需要从“单一粒子层”升级为近景、中景、远景、地表响应四层结构。

## 3.4 村庄环境与生活氛围系统

### 目标

把出生村庄做成真正值得停留、值得回望、能承载精神重量的空间，而不是功能性出生点。

### 当前状态

村庄布局、语义锚点和主流程作用已经打通；本轮新增统一氛围控制层，但视觉资产仍需持续升级。

### 已覆盖内容

1. 屋舍、羊圈、水井、集市、海边、村外小路等核心空间关系已建立。
2. 村庄与羊群、商人、牧羊人、梦境前后主流程已经形成闭环。
3. 本轮新增 `VillageAtmosphere`，统一驱动布棚摆动、烟雾上升、海雾、潮湿感、生活密度和梦后不安。
4. 现有占位动效已经不再完全靠分散的正弦波，而是开始读取环境与风场公共状态。

### 后续余项

1. 房屋构造、屋顶、门窗、梁柱、潮湿落地关系和暖窗层次需要继续提升。
2. 海边、集市、羊圈、水井需要从“能说明语义”升级为“具有空间质感与停留价值”。
3. 村庄的晨昏、梦前、梦后、海风转向等氛围状态要继续强化，并纳入展示样张。

## 3.5 生态角色与征兆载体系统

### 目标

让动物和人物不只是逻辑体，而是可信居民、风向线索和征兆载体。

### 当前状态

行为系统已具备第一版；角色外形和替身体系仍处于正式化早期。

### 已覆盖内容

1. 羊群、鸟群、鱼群、牧羊人、商人、占卜人的行为与调度已建立。
2. 生态状态、梦后联动、征兆联动和记事本记录已打通。
3. 生态角色资产已纳入程序化资产体系，并具备近景蓝图与基础动画角色槽位。

### 后续余项

1. 角色轮廓必须继续提升，避免近景继续显得像玩具几何。
2. 近景角色、中景替身、远景群体代理的正式 LOD 体系还要加强。
3. 生态行为要进一步吃统一风场和环境状态，而不是只在本地状态机里转。

## 3.6 地标巨构与远方奇观系统

### 目标

让地标承担“远方愿望的形体”这一职责，特别是沙暴中的巨大金字塔。

### 当前状态

金字塔、绿洲、残墙和显隐逻辑已有第一版，但震撼感和周边层次还不够。

### 已覆盖内容

1. 金字塔近中远三档蓝图和残墙、绿洲、遗物等周边元素已经建立。
2. 地标与梦境、感知、记事本和展示模式已经打通。
3. 地标可见性和沙暴显隐已有基础联动。

### 后续余项

1. 金字塔的阶梯、磨损、入口、底座、阴影、埋沙关系还需强化。
2. 绿洲湿沙、动物痕迹、废墟节奏、地下古城入口仍需深入推进。
3. 沙暴中的显现应进一步结合统一风场、环境快照和长期意愿，而不是靠单独规则。

## 3.7 意愿、梦境、感知与征兆系统

### 目标

让玩家在不被任务栏命令的情况下，仍然能够逐渐理解自己该往哪里去。

### 当前状态

已跑通第一段可玩闭环，且与村庄、梦境、生态、地标已有联动。

### 已覆盖内容

1. 意愿采样、主导意愿、主动感知、梦后回响和当前征兆状态已具备。
2. 记事本替代任务栏的方向已成立。
3. 征兆可通过光、风、鸟群、人物、梦境和地标轮廓表达。

### 后续余项

1. 征兆表现仍需更多依赖高质量环境与资产层，而不是靠逻辑状态本身解释自己。
2. 感知触发后的局部强化表现要更美、更自然、更具辨识度。

## 3.8 展示、截图与性能验收系统

### 目标

让高质量迭代可展示、可对比、可验证，而不是凭主观感觉继续叠系统。

### 当前状态

展示场景矩阵、日志、性能报告和部分截图清单逻辑已建立。

### 已覆盖内容

1. 六个视觉样张基线已建立。
2. 展示模式已经覆盖村庄、边界、地标、梦境、生态、第三人称等核心系统。
3. 日志和性能报告流程已经存在。

### 后续余项

1. 真正的截图落盘、前后样张归档、配置摘要与 commit 对照仍需补齐。
2. 新增统一风场、村庄氛围、重型程序化资产后，都必须进入性能报告与展示验收。
3. 所有关键视觉系统都要进入“截图 + 日志 + 性能”三重验证。

## 4. 结论

《道》当前最重要的不是继续扩玩法数量，而是把已经成立的世界规律与征兆旅程，升级成玩家愿意相信、愿意停留、愿意追寻的高质量世界。

接下来必须坚持以下原则：

1. 程序化高质量表现是正式路线，不是过渡路线。
2. 不因为程序化难而降低画质目标。
3. 所有系统都要往统一底座收束，尤其是风场、氛围、资产语义、LOD 和展示验收。
4. 每一轮开发都要同时推进“更美”和“更可持续”，而不是二选一。
